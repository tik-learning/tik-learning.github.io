Fungsi Logika Microsoft Excel 2016

Progress Pembelajaran Modul 7

1. Pengenalan Fungsi Logika

Fungsi logika digunakan untuk membuat Excel melakukan pengujian terhadap suatu kondisi dan menghasilkan keputusan berdasarkan kondisi tersebut.

Dengan fungsi logika, Excel dapat digunakan untuk membuat keputusan otomatis seperti:

  • Menentukan peserta Lulus atau Belum Lulus.
  • Menentukan apakah target tercapai.
  • Memberikan keterangan berdasarkan nilai.
  • Memeriksa apakah data memenuhi syarat tertentu.
  • Menangani data kosong atau error.
  • Membuat keputusan berdasarkan beberapa kondisi.
💡 Contoh sederhana:

Jika nilai peserta minimal 75 maka dinyatakan Lulus, jika kurang dari 75 maka Belum Lulus.

=IF(B2>=75,"Lulus","Belum Lulus")

2. TRUE dan FALSE

Fungsi logika bekerja dengan konsep nilai logika: TRUE dan FALSE.

Nilai Arti
TRUE Kondisi benar
FALSE Kondisi salah

Contoh

=80>=75

Hasilnya: TRUE

=60>=75

Hasilnya: FALSE

3. Operator Logika / Perbandingan

Sebelum menggunakan fungsi logika, kita perlu memahami operator perbandingan yang digunakan Excel.

Operator Arti Contoh
= Sama dengan A1=100
> Lebih besar dari A1>100
< Lebih kecil dari A1<100
>= Lebih besar atau sama dengan A1>=100
<= Lebih kecil atau sama dengan A1<=100
<> Tidak sama dengan A1<>100
💡 Ingat:

Operator <> berarti tidak sama dengan.

4. Fungsi AND

AND digunakan untuk menguji beberapa kondisi sekaligus.

Hasil AND adalah TRUE jika semua kondisi bernilai TRUE. Jika ada satu kondisi saja yang FALSE, hasilnya FALSE.

Sintaks

=AND(logical1,logical2,...)

Contoh

=AND(A1>=75,B1="Hadir")

Artinya:

  • Nilai minimal 75.
  • Status kehadiran harus "Hadir".

Kedua syarat harus terpenuhi.

Kondisi 1 Kondisi 2 Hasil AND
TRUE TRUE TRUE
TRUE FALSE FALSE
FALSE TRUE FALSE
FALSE FALSE FALSE

5. Fungsi OR

OR digunakan untuk menguji beberapa kondisi dan menghasilkan TRUE apabila minimal satu kondisi bernilai TRUE.

Sintaks

=OR(logical1,logical2,...)

Contoh

=OR(A1="Lulus",B1="Lulus")

Jika salah satu kondisi benar, hasilnya TRUE.

Kondisi 1 Kondisi 2 Hasil OR
TRUE TRUE TRUE
TRUE FALSE TRUE
FALSE TRUE TRUE
FALSE FALSE FALSE

6. Fungsi XOR

XOR merupakan fungsi logika yang menghasilkan TRUE jika jumlah kondisi TRUE adalah ganjil. Untuk dua kondisi, secara sederhana XOR menghasilkan TRUE jika hanya salah satu kondisi yang TRUE.

Sintaks

=XOR(logical1,logical2,...)

Contoh

=XOR(A1="Ya",B1="Ya")

Jika hanya salah satu A1 atau B1 bernilai "Ya", hasilnya TRUE.

Kondisi 1 Kondisi 2 Hasil XOR
TRUE TRUE FALSE
TRUE FALSE TRUE
FALSE TRUE TRUE
FALSE FALSE FALSE

7. Fungsi NOT

NOT digunakan untuk membalik nilai logika.

TRUE menjadi FALSE dan FALSE menjadi TRUE.

Sintaks

=NOT(logical)

Contoh

=NOT(A1="Lulus")

Jika A1 berisi "Lulus", maka hasil NOT adalah FALSE.

Kondisi NOT
TRUE FALSE
FALSE TRUE

8. Fungsi IF

IF adalah salah satu fungsi logika yang paling sering digunakan dalam Excel.

IF digunakan untuk menghasilkan satu nilai jika kondisi benar dan nilai lain jika kondisi salah.

Sintaks

=IF(logical_test,value_if_true,value_if_false)

Contoh 1 — Status Kelulusan

=IF(B2>=75,"Lulus","Belum Lulus")

Contoh 2 — Target Penjualan

=IF(C2>=10000000,"Target Tercapai","Belum Tercapai")

Contoh 3 — Status Kehadiran

=IF(D2>=80%,"Memenuhi","Tidak Memenuhi")

9. IF Bertingkat

IF dapat digunakan secara bertingkat untuk menghasilkan beberapa kategori.

Contoh Kategori Nilai

=IF(B2>=90,"A",IF(B2>=80,"B",IF(B2>=70,"C",IF(B2>=60,"D","E"))))
Nilai Grade
90–100 A
80–89 B
70–79 C
60–69 D
< 60 E
⚠️ Catatan Excel 2016:

IF bertingkat dapat menjadi panjang dan sulit dibaca jika kondisinya terlalu banyak. Pada Excel 2016, untuk kondisi yang banyak, kita dapat menggunakan kombinasi IF dengan fungsi lain seperti AND, OR, atau menggunakan tabel referensi dan VLOOKUP.

10. Kombinasi IF dan AND

IF dapat dikombinasikan dengan AND apabila keputusan memerlukan beberapa syarat sekaligus.

Contoh

Peserta dinyatakan lulus apabila nilai minimal 75 dan kehadiran minimal 80%.

=IF(AND(B2>=75,C2>=80%),"Lulus","Belum Lulus")

Kedua kondisi harus terpenuhi.

11. Kombinasi IF dan OR

IF + OR digunakan apabila cukup salah satu dari beberapa syarat yang terpenuhi.

Contoh

Peserta dapat memperoleh status "Prioritas" jika nilai minimal 90 atau kehadirannya 100%.

=IF(OR(B2>=90,C2=100%),"Prioritas","Reguler")

12. Kombinasi IF dan NOT

NOT dapat digunakan untuk membalik suatu kondisi.

Contoh

=IF(NOT(B2="Lulus"),"Perlu Evaluasi","Selesai")

Jika B2 bukan "Lulus", hasilnya "Perlu Evaluasi".

13. Fungsi IS

Kelompok fungsi IS digunakan untuk memeriksa jenis atau kondisi suatu nilai dalam cell.

Fungsi IS biasanya menghasilkan nilai TRUE atau FALSE.

Fungsi IS yang umum pada Excel 2016

Fungsi Kegunaan
ISBLANK Memeriksa apakah cell kosong
ISNUMBER Memeriksa apakah data berupa angka
ISTEXT Memeriksa apakah data berupa teks
ISNONTEXT Memeriksa apakah data bukan teks
ISLOGICAL Memeriksa apakah data berupa TRUE/FALSE
ISERROR Memeriksa apakah hasil berupa error
ISERR Memeriksa error selain #N/A
ISNA Memeriksa apakah hasilnya #N/A
ISEVEN Memeriksa apakah angka genap
ISODD Memeriksa apakah angka ganjil

14. ISBLANK

ISBLANK digunakan untuk memeriksa apakah sebuah cell benar-benar kosong.

Sintaks

=ISBLANK(A1)

Contoh dengan IF

=IF(ISBLANK(A1),"Belum Diisi","Sudah Diisi")

Formula ini berguna untuk membuat pemeriksaan kelengkapan formulir atau data administrasi.

15. ISNUMBER

ISNUMBER digunakan untuk memeriksa apakah suatu nilai merupakan angka.

=ISNUMBER(A1)

Contoh

=IF(ISNUMBER(A1),"Data Angka","Bukan Angka")

16. ISTEXT

ISTEXT digunakan untuk memeriksa apakah suatu nilai berupa teks.

=ISTEXT(A1)

Contoh

=IF(ISTEXT(A1),"Teks","Bukan Teks")

17. ISEVEN dan ISODD

Kedua fungsi ini digunakan untuk memeriksa apakah sebuah angka merupakan bilangan genap atau ganjil.

ISEVEN

=ISEVEN(A1)

Menghasilkan TRUE jika angka merupakan bilangan genap.

ISODD

=ISODD(A1)

Menghasilkan TRUE jika angka merupakan bilangan ganjil.

Contoh dengan IF

=IF(ISEVEN(A1),"Genap","Ganjil")

18. ISERROR

ISERROR digunakan untuk memeriksa apakah sebuah hasil formula menghasilkan error.

=ISERROR(A1/B1)

Jika A1/B1 menghasilkan error, hasil ISERROR adalah TRUE.

Contoh dengan IF

=IF(ISERROR(A1/B1),"Tidak dapat dihitung",A1/B1)

19. IFERROR

IFERROR digunakan untuk memberikan hasil alternatif apabila sebuah formula menghasilkan error.

Sintaks

=IFERROR(value,value_if_error)

Contoh

=IFERROR(A2/B2,0)

Jika A2/B2 menghasilkan error, Excel akan menampilkan 0.

Contoh lain

=IFERROR(A2/B2,"Tidak dapat dihitung")

Jika terjadi error, Excel akan menampilkan "Tidak dapat dihitung".

💡 IFERROR sangat berguna

IFERROR banyak digunakan untuk membuat laporan terlihat lebih rapi sehingga pesan error tidak muncul kepada pengguna.

20. Perbedaan ISERROR dan IFERROR

Fungsi Kegunaan
ISERROR Memeriksa apakah hasil merupakan error
IFERROR Mengganti hasil error dengan nilai yang kita tentukan

ISERROR

=IF(ISERROR(A2/B2),"Error","OK")

IFERROR

=IFERROR(A2/B2,"Error")

21. Fungsi IFS

IFS digunakan untuk menguji beberapa kondisi tanpa harus membuat IF bertingkat yang panjang.

⚠️ Penting untuk Excel 2016:

Fungsi IFS tidak tersedia pada Excel 2016 standar. IFS diperkenalkan pada versi Excel yang lebih baru. Karena modul ini ditujukan untuk Excel 2016, peserta sebaiknya menggunakan IF bertingkat sebagai pengganti IFS.

Contoh IFS pada Excel versi yang mendukung

=IFS(B2>=90,"A",B2>=80,"B",B2>=70,"C",B2>=60,"D",B2<60,"E")

Alternatif Excel 2016

=IF(B2>=90,"A",IF(B2>=80,"B",IF(B2>=70,"C",IF(B2>=60,"D","E"))))

22. Fungsi Logika Lain yang Sejenis

Selain fungsi utama di atas, beberapa fungsi lain yang berkaitan dengan logika dan pemeriksaan data pada Excel 2016 antara lain:

Fungsi Kegunaan

FALSE() Menghasilkan nilai FALSE
ISERROR Memeriksa semua jenis error
ISERR Memeriksa error selain #N/A
ISNA Memeriksa error #N/A
ISBLANK Memeriksa cell kosong
ISNUMBER Memeriksa data angka
ISTEXT Memeriksa data teks
ISNONTEXT Memeriksa data bukan teks
ISLOGICAL Memeriksa TRUE atau FALSE
ISEVEN Memeriksa angka genap
ISODD Memeriksa angka ganjil

23. Contoh Praktik: Menentukan Status Peserta

Misalkan terdapat data berikut:

Nama Nilai Kehadiran Status
Andi 85 90% ?
Budi 70 95% ?
Citra 90 75% ?

Syarat lulus:

  • Nilai minimal 75.
  • Kehadiran minimal 80%.

Gunakan kombinasi IF dan AND:

=IF(AND(B2>=75,C2>=80%),"Lulus","Belum Lulus")

Formula dapat disalin ke baris berikutnya menggunakan Fill Handle.

24. Contoh Praktik: Menentukan Peserta Prioritas

Peserta dianggap prioritas jika memenuhi salah satu kondisi:

  • Nilai minimal 90, atau
  • Kehadiran 100%.
=IF(OR(B2>=90,C2=100%),"Prioritas","Reguler")

25. Contoh Praktik: Menghindari Error Pembagian

Misalnya jumlah penjualan berada pada B2 dan jumlah barang berada pada C2.

Formula biasa:

=B2/C2

Jika C2 bernilai 0, Excel akan menghasilkan #DIV/0!.

Untuk membuat laporan lebih rapi, gunakan:

=IFERROR(B2/C2,0)

Jika terjadi error, hasil akan menjadi 0.

27. Catatan Penting untuk Excel 2016

⚠️ Perhatikan versi Excel

Dalam modul ini kita menggunakan pendekatan yang kompatibel dengan Microsoft Excel 2016.

Fungsi IFS yang sering digunakan pada Excel versi baru tidak tersedia pada Excel 2016 standar. Oleh karena itu, peserta Excel 2016 perlu menguasai IF bertingkat.

28. Latihan Mandiri

Cobalah membuat formula untuk menyelesaikan kasus berikut:

  1. Jika nilai minimal 75, tampilkan "Lulus", jika tidak tampilkan "Belum Lulus".
  2. Jika nilai minimal 75 dan kehadiran minimal 80%, tampilkan "Lulus".
  3. Jika nilai minimal 90 atau kehadiran 100%, tampilkan "Prioritas".
  4. Periksa apakah sebuah cell kosong menggunakan ISBLANK.
  5. Periksa apakah sebuah cell berisi angka menggunakan ISNUMBER.
  6. Periksa apakah sebuah cell berisi teks menggunakan ISTEXT.
  7. Buat formula yang menampilkan "Genap" atau "Ganjil" menggunakan ISEVEN.
  8. Buat formula yang mengganti error pembagian dengan angka 0 menggunakan IFERROR.
  9. Buat kategori nilai A sampai E menggunakan IF bertingkat.

29. Kesimpulan

Fungsi logika merupakan salah satu kemampuan penting dalam Microsoft Excel karena memungkinkan Excel melakukan pengambilan keputusan secara otomatis.

Dengan menguasai IF, AND, OR, XOR, NOT, fungsi IS, IFERROR dan IF bertingkat, peserta dapat membuat lembar kerja yang lebih otomatis, informatif, dan profesional.

📌 Ingat konsep dasarnya:
  • AND → semua syarat harus benar.
  • OR → minimal satu syarat benar.
  • XOR → jumlah kondisi TRUE harus ganjil.
  • NOT → membalik kondisi.
  • IF → jika kondisi benar/salah.
  • IS → memeriksa jenis atau kondisi data.
  • IFERROR → mengganti hasil error.
