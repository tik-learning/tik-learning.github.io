1. Apa Itu Macro?

Macro adalah sekumpulan instruksi yang digunakan untuk mengotomatisasi pekerjaan berulang di Microsoft Excel.

Dengan Macro, pekerjaan yang biasanya dilakukan secara manual berulang kali dapat dijalankan dengan satu perintah.

Contoh pekerjaan berulang:
  • Memberikan format pada laporan.
  • Menghapus data tertentu.
  • Membuat laporan secara otomatis.
  • Menyalin data dari satu worksheet ke worksheet lain.
  • Mengatur ukuran kolom.
  • Membuat tabel laporan.
  • Membersihkan data.
Contoh sederhana:

Jika setiap hari kita harus melakukan 10 langkah untuk membuat laporan, Macro dapat digunakan untuk menjalankan langkah-langkah tersebut secara otomatis.

2. Apa Itu VBA?

VBA (Visual Basic for Applications) adalah bahasa pemrograman yang digunakan untuk membuat dan mengembangkan Macro di Microsoft Office.

Pada Excel, VBA memungkinkan kita membuat otomatisasi yang lebih fleksibel dibandingkan hanya menggunakan Record Macro.

Istilah Pengertian
Macro Serangkaian perintah untuk mengotomatisasi pekerjaan.
VBA Bahasa pemrograman yang digunakan untuk membuat Macro.
Visual Basic Editor Lingkungan untuk melihat dan mengedit kode VBA.
Module Tempat penyimpanan kode Macro VBA.

3. Mengaktifkan Tab Developer

Untuk menggunakan Macro dan VBA, tab Developer perlu diaktifkan.

Langkah pada Excel 2016

1

Klik File.

2

Klik Options.

3

Pilih Customize Ribbon.

4

Pada bagian Main Tabs, centang Developer.

5

Klik OK.

Setelah itu tab Developer akan muncul pada Ribbon Excel.

4. Keamanan Macro

Macro dapat menjalankan kode sehingga Excel memiliki fitur keamanan untuk mengontrol Macro yang berasal dari file.

Macro Security

Pengaturan keamanan dapat ditemukan melalui:

File → Options → Trust Center → Trust Center Settings → Macro Settings

Beberapa pilihan keamanan Macro antara lain:

Pengaturan Keterangan
Disable all macros with notification Macro dinonaktifkan tetapi pengguna diberi pilihan untuk mengaktifkannya.
Disable all macros without notification Macro dinonaktifkan tanpa pemberitahuan.
Enable all macros Semua Macro diizinkan berjalan.
⚠️ Penting:

Jangan sembarangan mengaktifkan Macro dari file yang tidak dipercaya. Macro dapat berisi kode yang menjalankan tindakan pada komputer.

Untuk latihan, gunakan file Macro yang dibuat sendiri atau file dari sumber yang terpercaya.

5. Format File yang Mendukung Macro

Workbook yang berisi Macro tidak sebaiknya disimpan menggunakan format .xlsx karena format tersebut tidak menyimpan Macro VBA.

Format Keterangan
.xlsx Workbook Excel biasa, tidak menyimpan Macro VBA.
.xlsm Excel Macro-Enabled Workbook dan dapat menyimpan Macro.
.xlsb Excel Binary Workbook dan dapat menyimpan Macro.
.xls Format workbook Excel versi lama.
💡 Untuk latihan Macro Excel 2016:

Gunakan format:

Excel Macro-Enabled Workbook (*.xlsm)

6. Record Macro

Record Macro adalah fitur untuk merekam tindakan yang kita lakukan di Excel dan mengubahnya menjadi kode VBA.

Fitur ini sangat berguna bagi pemula yang belum menguasai VBA.

Cara Record Macro

1

Buka tab Developer.

2

Klik Record Macro.

3

Masukkan nama Macro.

4

Tentukan tempat penyimpanan Macro.

5

Klik OK.

6

Lakukan pekerjaan yang ingin direkam.

7

Klik Stop Recording.

7. Praktik Record Macro Sederhana

Kita akan membuat Macro untuk memberikan format sederhana pada sebuah judul laporan.

Langkah

  1. Buat teks "LAPORAN DATA PESERTA" pada cell A1.
  2. Aktifkan Record Macro.
  3. Beri nama Macro: FormatJudul.
  4. Pilih A1.
  5. Buat tulisan menjadi Bold.
  6. Atur alignment menjadi Center.
  7. Atur ukuran font.
  8. Hentikan Record Macro.

Macro tersebut sekarang dapat digunakan kembali untuk menjalankan format yang sama.

8. Menjalankan Macro

Macro yang sudah dibuat dapat dijalankan melalui beberapa cara.

Cara 1 — Developer

Developer → Macros → pilih Macro → Run

Cara 2 — Shortcut

Macro dapat diberikan shortcut ketika dibuat.

Cara 3 — Tombol

Macro dapat dihubungkan dengan Button pada worksheet.

9. Use Relative References

Pada Record Macro terdapat pilihan Use Relative References.

Pilihan ini menentukan apakah Macro merekam posisi cell secara relatif terhadap cell aktif.

Perbedaan

Absolute Reference Relative Reference
Menggunakan posisi cell tertentu. Mengikuti posisi relatif terhadap cell aktif.
Cocok untuk pekerjaan pada lokasi tertentu. Cocok untuk pekerjaan yang ingin diterapkan pada posisi berbeda.
Contoh:

Jika Macro direkam untuk memformat cell di sebelah kanan cell aktif, Relative References memungkinkan pola tersebut digunakan ketika cell aktif berpindah.

10. Mengenal Visual Basic Editor

Visual Basic Editor atau VBE digunakan untuk melihat, membuat, dan mengedit kode VBA.

Cara membuka VBE

  • Developer → Visual Basic
  • Shortcut: Alt + F11

Di dalam VBE kita akan menemukan beberapa bagian penting:

Bagian Fungsi
Project Explorer Menampilkan workbook dan objek VBA.
Code Window Tempat menulis dan mengedit kode.
Properties Window Menampilkan properti objek.
Immediate Window Dapat digunakan untuk pengujian dan debugging sederhana.

11. Module VBA

Kode Macro biasanya disimpan di dalam sebuah Module.

Cara membuat Module

Alt + F11 ↓ Insert ↓ Module

Setelah Module dibuat, kita dapat menulis prosedur VBA.

12. Struktur Dasar VBA

Macro VBA biasanya menggunakan struktur Sub...End Sub.

Sub ContohMacro() MsgBox "Halo, Excel!" End Sub

Keterangan:

  • Sub menandai awal prosedur.
  • ContohMacro adalah nama Macro.
  • MsgBox menampilkan pesan.
  • End Sub menandai akhir prosedur.

13. Mengenal Object dalam VBA

Excel memiliki banyak objek yang dapat dikendalikan menggunakan VBA.

Object Contoh
Application Aplikasi Excel.
Workbook File Excel yang sedang dibuka.
Worksheet Lembar kerja.
Range Satu atau beberapa cell.
Cell Sel pada worksheet.

Contoh

Range("A1").Value = "Laporan Peserta"

Kode tersebut mengisi cell A1 dengan teks "Laporan Peserta".

14. Property dan Method

Dalam VBA terdapat istilah Property dan Method.

Property

Property merupakan karakteristik atau nilai dari suatu objek.

Range("A1").Value = "Excel"

Value merupakan property.

Method

Method merupakan tindakan yang dapat dilakukan terhadap objek.

Range("A1").ClearContents

ClearContents merupakan method.

15. Menggunakan Range

Mengisi Cell

Range("A1").Value = "Nama Peserta"

Mengisi Beberapa Cell

Range("A1:A10").Value = "Peserta"

Mengubah Format

Range("A1").Font.Bold = True

Menghapus Isi

Range("A1").ClearContents

16. Menggunakan Cells

Selain Range, kita dapat menggunakan objek Cells.

Cells(1,1).Value = "Nama"

Artinya:

  • 1 = nomor baris
  • 1 = nomor kolom

Sehingga kode tersebut mengacu pada cell A1.

Cells(2,1).Value = "Andi"

Kode tersebut mengisi cell A2.

17. Variabel VBA

Variabel digunakan untuk menyimpan nilai sementara selama Macro berjalan.

Contoh

Dim nama As String nama = "Andi" MsgBox nama

Pada contoh tersebut:

  • Dim digunakan untuk mendeklarasikan variabel.
  • nama adalah nama variabel.
  • String adalah tipe data teks.

18. IF...THEN dalam VBA

IF digunakan untuk membuat keputusan berdasarkan kondisi tertentu.

Contoh

Sub CekNilai() Dim nilai As Double nilai = Range("A1").Value If nilai >= 75 Then MsgBox "Lulus" Else MsgBox "Belum Lulus" End If End Sub

Jika nilai di A1 minimal 75 maka akan muncul pesan Lulus.

19. Perulangan For...Next

For...Next digunakan untuk menjalankan perintah berulang.

Contoh

Sub IsiNomor() Dim i As Integer For i = 1 To 10 Cells(i,1).Value = i Next i End Sub

Macro tersebut akan mengisi angka 1 sampai 10 pada cell A1 sampai A10.

20. MsgBox

MsgBox digunakan untuk menampilkan pesan kepada pengguna.

MsgBox "Data berhasil diproses."

MsgBox dapat digunakan sebagai pemberitahuan setelah Macro selesai melakukan suatu pekerjaan.

21. Membuat Tombol Macro

Macro dapat dijalankan menggunakan tombol sehingga pengguna tidak perlu membuka menu Developer setiap kali menjalankan Macro.

Langkah

  1. Buka tab Developer.
  2. Klik Insert.
  3. Pilih Button (Form Control).
  4. Gambar tombol pada worksheet.
  5. Pilih Macro yang ingin dijalankan.
  6. Klik OK.

Teks tombol dapat diubah menjadi:

PROSES DATA

22. Praktik 1 — Membuat Macro Sapaan

Buat Module baru kemudian masukkan kode berikut:

Sub Sapaan() MsgBox "Selamat datang di Pelatihan Microsoft Excel!" End Sub

Jalankan Macro tersebut menggunakan tombol Run pada Visual Basic Editor.

23. Praktik 2 — Mengisi Data Otomatis

Macro berikut akan mengisi nomor 1 sampai 20 secara otomatis.

Sub IsiNomorPeserta() Dim i As Integer For i = 1 To 20 Cells(i,1).Value = i Next i MsgBox "Nomor peserta berhasil dibuat." End Sub

24. Praktik 3 — Pemeriksaan Nilai Otomatis

Misalnya nilai peserta berada pada kolom B. Kita ingin menentukan status pada kolom C.

Sub CekKelulusan() Dim i As Integer For i = 2 To 20 If Cells(i,2).Value >= 75 Then Cells(i,3).Value = "Lulus" Else Cells(i,3).Value = "Belum Lulus" End If Next i MsgBox "Pemeriksaan nilai selesai." End Sub

Macro tersebut memeriksa nilai pada B2:B20 kemudian menuliskan hasil pada C2:C20.

25. Praktik 4 — Format Laporan Otomatis

Macro berikut dapat digunakan untuk memberikan format sederhana pada header laporan.

Sub FormatHeader() With Range("A1:E1") .Font.Bold = True .HorizontalAlignment = xlCenter End With MsgBox "Format header selesai." End Sub

26. Praktik 5 — Membersihkan Data

Macro dapat digunakan untuk menghapus isi area tertentu.

Sub BersihkanData() Range("A2:E100").ClearContents MsgBox "Data berhasil dibersihkan." End Sub
⚠️ Perhatian:

Pastikan range yang akan dihapus benar. Macro yang menggunakan ClearContents dapat menghapus data dalam range tersebut.

27. Menggunakan With...End With

With digunakan untuk menjalankan beberapa perintah pada objek yang sama tanpa menuliskan objek berulang kali.

With Range("A1") .Font.Bold = True .Font.Size = 14 .HorizontalAlignment = xlCenter End With

Kode tersebut menerapkan beberapa property pada cell A1.

28. Konsep Otomasi Tingkat Lanjut

Setelah memahami dasar Macro dan VBA, otomasi dapat dikembangkan menjadi sistem yang lebih kompleks.

  • Otomatisasi pembuatan laporan.
  • Otomatisasi rekap data.
  • Otomatisasi pemeriksaan data.
  • Otomatisasi format laporan.
  • Otomatisasi pembuatan nomor dokumen.
  • Otomatisasi pemindahan data antar-sheet.
  • Otomatisasi filter data.
  • Otomatisasi pembuatan file laporan.

29. Contoh Otomasi Laporan Peserta

Misalnya tersedia data peserta dengan struktur:

A B C D
No Nama Nilai Status

Macro dapat digunakan untuk:

  1. Mengisi nomor peserta.
  2. Mengecek nilai.
  3. Menentukan status.
  4. Memberikan format header.
  5. Menyesuaikan lebar kolom.
  6. Menampilkan pesan bahwa proses selesai.

Contoh kode

Sub BuatLaporan() Dim i As Integer For i = 2 To 100 Cells(i,1).Value = i - 1 If Cells(i,3).Value >= 75 Then Cells(i,4).Value = "Lulus" Else Cells(i,4).Value = "Belum Lulus" End If Next i With Range("A1:D1") .Font.Bold = True .HorizontalAlignment = xlCenter End With Columns("A:D").AutoFit MsgBox "Laporan berhasil diproses." End Sub

30. Debugging Macro

Debugging adalah proses mencari dan memperbaiki kesalahan pada kode VBA.

Beberapa penyebab error:

  • Salah mengetik nama objek.
  • Salah menulis sintaks.
  • Range tidak sesuai.
  • Tipe data tidak sesuai.
  • Objek worksheet tidak ditemukan.

Fitur penting pada VBA Editor

Fitur Kegunaan
Run Menjalankan Macro.
Break Menghentikan sementara eksekusi kode.
Step Into Menjalankan kode langkah demi langkah.
Immediate Window Menguji perintah VBA secara langsung.

31. Kesalahan yang Sering Terjadi

Masalah Kemungkinan Penyebab Solusi
Macro tidak muncul File bukan format Macro-enabled. Simpan sebagai .xlsm.
Macro tidak berjalan Macro diblokir. Periksa Macro Security.
Kode error Sintaks VBA salah. Periksa kode.
Data salah Range tidak tepat. Periksa alamat Range.
Macro menghapus data ClearContents diarahkan ke range yang salah. Periksa range sebelum menjalankan.

  3. Menentukan status Lulus atau Belum Lulus.
  4. Memformat header tabel.

💡 33. Tips Menggunakan Macro

1. Gunakan nama Macro yang jelas

Contoh: BuatLaporan, CekKelulusan, atau FormatData.

2. Simpan workbook sebagai .xlsm

Gunakan Excel Macro-Enabled Workbook untuk menyimpan VBA.

3. Uji Macro dengan data contoh

Jangan langsung menjalankan Macro pada data penting.

4. Berikan tombol yang jelas

Contohnya "PROSES DATA" atau "BUAT LAPORAN".

5. Buat backup data

Simpan salinan data sebelum menjalankan Macro yang mengubah atau menghapus data.
