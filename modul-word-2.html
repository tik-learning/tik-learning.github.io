📘 Modul 2 — Membuat dan Mengelola Dokumen

Microsoft Word 2016

Pada modul ini peserta mempelajari berbagai keterampilan dasar untuk membuat, mengedit, menyimpan, membuka, dan mengelola dokumen.

🎯 Tujuan Pembelajaran

Setelah menyelesaikan modul ini, peserta diharapkan mampu:

  • Membuat dokumen baru di Microsoft Word 2016.
  • Membuka dokumen yang sudah tersimpan.
  • Mengetik dan mengedit teks.
  • Menyimpan dokumen dengan benar.
  • Memahami perbedaan Save dan Save As.
  • Membuka kembali dokumen yang terakhir digunakan.
  • Memilih teks menggunakan mouse dan keyboard.
  • Menggunakan Copy, Cut, dan Paste.
  • Menggunakan Undo dan Redo.
  • Menggunakan Find & Replace.

1. 📄 Membuat Dokumen Baru

Dokumen baru digunakan ketika kita ingin membuat file Word dari awal.

📌 Cara 1 — Melalui Start Screen

  1. Buka Microsoft Word 2016.
  2. Pada Start Screen, pilih Blank Document.
  3. Word akan membuka lembar dokumen kosong.
  4. Dokumen siap digunakan untuk mengetik.

⌨️ Cara 2 — Menggunakan Keyboard

Tekan:

Ctrl + N

Shortcut tersebut akan membuat dokumen Word baru.

💡 Tips:
Sebelum mulai mengetik, biasakan menentukan terlebih dahulu tujuan dan isi dokumen yang akan dibuat.

2. 📂 Membuka Dokumen yang Sudah Ada

Dokumen yang sebelumnya sudah disimpan dapat dibuka kembali untuk dibaca atau diedit.

Langkah-langkah

  1. Buka Microsoft Word.
  2. Pilih File.
  3. Pilih Open.
  4. Pilih lokasi penyimpanan dokumen.
  5. Cari file Word yang ingin dibuka.
  6. Pilih dokumen.
  7. Klik Open.
⌨️ Shortcut:

Ctrl + O

Digunakan untuk membuka dokumen.

💡 Tips:
Perhatikan lokasi penyimpanan file. Dokumen dapat berada di Documents, Desktop, flashdisk, OneDrive, atau folder lainnya.

3. ⌨️ Mengetik dan Mengedit Teks

Setelah dokumen terbuka, kita dapat mulai mengetik teks.

Klik pada area dokumen, kemudian mulai memasukkan teks menggunakan keyboard.

Contoh Teks

UPTD BLK Kabupaten Subang menyelenggarakan pelatihan berbasis kompetensi untuk meningkatkan keterampilan peserta agar siap memasuki dunia kerja maupun mengembangkan usaha mandiri.

✏️ Mengedit Teks

Mengedit berarti melakukan perubahan terhadap teks yang sudah diketik.

  • Menambahkan kata.
  • Menghapus kata.
  • Mengubah kalimat.
  • Memperbaiki kesalahan pengetikan.
  • Memindahkan teks.

⌨️ Tombol yang Sering Digunakan

  • Backspace — menghapus karakter di sebelah kiri kursor.
  • Delete — menghapus karakter di sebelah kanan kursor.
  • Enter — membuat paragraf atau baris baru.
  • Spacebar — memberikan jarak antar kata.
💡 Tips:
Jangan menggunakan Spacebar berkali-kali untuk membuat jarak atau posisi teks. Gunakan fitur Paragraph, Alignment, Tab, atau Table sesuai kebutuhan.

4. 💾 Menyimpan Dokumen

Menyimpan dokumen sangat penting agar pekerjaan tidak hilang.

Langkah-langkah

  1. Klik File.
  2. Pilih Save.
  3. Tentukan lokasi penyimpanan.
  4. Masukkan nama file.
  5. Klik Save.
⌨️ Shortcut:

Ctrl + S
💡 Kebiasaan yang baik:
Biasakan menekan Ctrl + S secara berkala, terutama setelah melakukan perubahan penting.

5. 💾 Save dan Save As

Kedua fitur ini sering dianggap sama, padahal memiliki fungsi yang berbeda.

💾 Save

Save digunakan untuk menyimpan perubahan pada file yang sedang dikerjakan.

Contoh: Anda memiliki file Laporan_Pelatihan.docx. Setelah melakukan perubahan, tekan Ctrl + S.

Perubahan akan disimpan pada file yang sama.

📑 Save As

Save As digunakan untuk menyimpan dokumen sebagai file baru dengan nama atau lokasi yang berbeda.

Contoh:

Laporan_Pelatihan.docx → Laporan_Pelatihan_Final.docx

Gunakan:

File → Save As

Fitur Fungsi
Save Menyimpan perubahan pada dokumen yang sama.
Save As Membuat salinan atau versi baru dari dokumen.

6. 🕘 Membuka Dokumen Terakhir

Microsoft Word menyediakan daftar dokumen yang baru saja digunakan.

Langkah-langkah

  1. Buka Microsoft Word.
  2. Pilih File.
  3. Pilih Open.
  4. Lihat bagian Recent.
  5. Pilih dokumen yang ingin dibuka.
💡 Tips:
Daftar Recent dapat mempercepat proses membuka dokumen yang sering digunakan.

7. ❌ Menutup Dokumen

Setelah selesai bekerja, dokumen dapat ditutup tanpa harus menutup aplikasi Microsoft Word.

Langkah-langkah

  1. Klik File.
  2. Pilih Close.

Anda juga dapat menggunakan tombol X pada jendela aplikasi.

⚠️ Perhatian:
Pastikan dokumen sudah disimpan sebelum ditutup, terutama jika terdapat perubahan yang belum disimpan.

8. 🖱️ Memilih Teks

Sebelum melakukan tindakan seperti Copy, Cut, Delete, atau mengubah format, teks harus dipilih terlebih dahulu.

Memilih dengan Mouse

Klik dan tahan tombol mouse, kemudian geser melewati teks yang ingin dipilih.

Memilih Satu Kata

Klik dua kali pada kata tersebut.

Memilih Seluruh Dokumen

Ctrl + A

Digunakan untuk memilih seluruh isi dokumen.

💡 Tips:
Pastikan bagian teks yang dipilih sudah benar sebelum melakukan tindakan seperti Delete atau Cut.

9. ✂️ Copy, Cut, dan Paste

📋 Copy

Copy digunakan untuk membuat salinan teks tanpa menghilangkan teks asli.

Ctrl + C

✂️ Cut

Cut digunakan untuk memindahkan teks dari satu tempat ke tempat lain.

Ctrl + X

📌 Paste

Paste digunakan untuk menempelkan hasil Copy atau Cut.

Ctrl + V

📊 Ringkasan Shortcut

Perintah Shortcut Fungsi
Copy Ctrl + C Menyalin teks
Cut Ctrl + X Memindahkan teks
Paste Ctrl + V Menempelkan teks

10. ↩️ Undo dan Redo

↩️ Undo

Undo digunakan untuk membatalkan tindakan sebelumnya.

Ctrl + Z

Contoh: jika Anda tidak sengaja menghapus sebuah paragraf, gunakan Ctrl + Z untuk membatalkan tindakan tersebut.

↪️ Redo

Redo digunakan untuk mengulangi kembali tindakan yang sebelumnya dibatalkan.

Ctrl + Y
💡 Tips:
Jangan panik ketika melakukan kesalahan saat mengedit dokumen. Periksa apakah tindakan tersebut dapat dibatalkan menggunakan Ctrl + Z.

11. 🔎 Mencari dan Mengganti Teks

🔎 Find

Find digunakan untuk mencari teks tertentu di dalam dokumen.

Ctrl + F

Masukkan kata yang ingin dicari pada kotak pencarian.

🔄 Replace

Replace digunakan untuk mengganti kata tertentu dengan kata lain.

Ctrl + H

Contoh:

Find what: BLK Subang

Replace with: UPTD BLK Kabupaten Subang

⚠️ Replace All

Replace All digunakan untuk mengganti semua teks yang ditemukan sekaligus.

Gunakan fitur ini dengan hati-hati dan pastikan kata yang dicari memang ingin diganti seluruhnya.

11. 📝 Latihan Praktik Modul 2

Praktik 1 — Membuat Dokumen

Buat dokumen baru di Microsoft Word 2016.

Ketik teks berikut:

PROFIL UPTD BLK KABUPATEN SUBANG

UPTD BLK Kabupaten Subang merupakan tempat pelatihan keterampilan yang bertujuan meningkatkan kompetensi peserta agar siap memasuki dunia kerja maupun mengembangkan usaha mandiri.

Praktik 2 — Mengedit Teks

Tambahkan kalimat berikut:

Pelatihan dilaksanakan berdasarkan kebutuhan kompetensi dan perkembangan teknologi.

Kemudian periksa kembali apakah terdapat kesalahan pengetikan.

Praktik 3 — Copy dan Paste

  1. Pilih kalimat yang baru saja ditambahkan.
  2. Tekan Ctrl + C.
  3. Pindahkan kursor ke tempat lain.
  4. Tekan Ctrl + V.

Praktik 4 — Cut dan Paste

  1. Pilih salah satu paragraf.
  2. Tekan Ctrl + X.
  3. Pindahkan kursor ke posisi lain.
  4. Tekan Ctrl + V.

Praktik 5 — Find & Replace

Gunakan Ctrl + H.

Cari: BLK Kabupaten Subang

Ganti menjadi: UPTD BLK Kabupaten Subang

Periksa kembali hasil penggantian.

Praktik 6 — Save As

Simpan dokumen menggunakan:

File → Save As

Gunakan nama file:

Latihan_Modul_2_NamaPeserta.docx

Contoh:

Latihan_Modul_2_AdeSuhendar.docx
