Modul 2

Mengelola Slide dan Memformat Teks

📚 Tentang Modul

Pada modul ini peserta akan mempelajari cara mengelola slide dan memformat teks pada Microsoft PowerPoint 2016.

Materi dimulai dari membuat, menghapus, menyalin dan memindahkan slide, kemudian dilanjutkan dengan pengaturan layout, section, ukuran slide, serta berbagai teknik pemformatan teks.

🎯 Tujuan Pembelajaran

Setelah menyelesaikan modul ini, peserta diharapkan mampu:

  • Membuat slide baru.
  • Menghapus slide.
  • Menyalin atau menggandakan slide.
  • Memindahkan urutan slide.
  • Mengubah layout slide.
  • Menggunakan Section.
  • Mengubah ukuran slide.
  • Membuat dan menggunakan Text Box.
  • Mengubah jenis dan ukuran huruf.
  • Menggunakan Bold, Italic, dan Underline.
  • Membuat WordArt.
  • Menggunakan Bullet dan Numbering.
  • Mengatur Line Spacing.
  • Mengatur Indent.

1. Membuat Slide Baru

Slide baru digunakan untuk menambahkan halaman atau bagian baru dalam sebuah presentasi.

Cara Membuat Slide Baru

Home → New Slide

Cara cepat menggunakan keyboard:

⌨️ Ctrl + M

Shortcut Ctrl + M digunakan untuk membuat slide baru.

Langkah-langkah

1
Pilih slide yang menjadi posisi sebelum slide baru.
2
Klik tab Home.
3
Klik New Slide.
4
Slide baru akan muncul setelah slide yang dipilih.

2. Menghapus Slide

Slide yang tidak diperlukan dapat dihapus dari presentasi.

Cara Menghapus Slide

  1. Pilih slide pada Thumbnail Pane.
  2. Klik kanan pada slide.
  3. Pilih Delete Slide.
💡 Cara cepat:

Pilih slide kemudian tekan tombol Delete pada keyboard.

3. Menyalin atau Menggandakan Slide

Fitur Duplicate Slide digunakan untuk membuat salinan slide tanpa harus membuat ulang isi slide.

Cara Menggandakan Slide

  1. Pilih slide yang ingin digandakan.
  2. Klik kanan pada slide.
  3. Pilih Duplicate Slide.
⌨️ Shortcut:

Ctrl + D

4. Memindahkan Urutan Slide

Urutan slide dapat diubah sesuai alur presentasi.

Cara Memindahkan Slide

  1. Pilih slide pada Thumbnail Pane.
  2. Klik dan tahan slide.
  3. Seret slide ke posisi yang diinginkan.
  4. Lepaskan tombol mouse.
💡 Tips:

Untuk presentasi dengan banyak slide, gunakan View → Slide Sorter.

5. Mengubah Layout Slide

Layout menentukan susunan tempat judul, teks, gambar, dan objek lainnya pada sebuah slide.

Home → Layout

Jenis Layout

Layout Fungsi
Title Slide Digunakan untuk slide judul.
Title and Content Judul dan satu area isi.
Section Header Untuk judul bagian atau section.
Two Content Memiliki dua area isi.
Comparison Untuk membandingkan dua informasi.
Title Only Hanya menyediakan area judul.
Blank Slide kosong tanpa placeholder.
Content with Caption Isi dengan keterangan.
Picture with Caption Gambar dengan keterangan.

6. Menggunakan Section

Section digunakan untuk mengelompokkan slide berdasarkan topik atau bagian tertentu.

Contoh pembagian Section:

Section 1 — Pendahuluan
Slide 1–3

Section 2 — Materi
Slide 4–10

Section 3 — Latihan
Slide 11–13

Section 4 — Penutup
Slide 14–15

Cara Membuat Section

  1. Pilih slide yang menjadi awal bagian baru.
  2. Klik kanan pada slide.
  3. Pilih Add Section.
  4. Masukkan nama Section.
  5. Klik Rename.
💡 Manfaat Section

Section sangat membantu mengelola presentasi yang memiliki banyak slide.

7. Mengubah Ukuran Slide

Ukuran slide dapat disesuaikan dengan perangkat atau kebutuhan presentasi.

Design → Slide Size
Ukuran Perbandingan Penggunaan
Standard 4 : 3 Perangkat atau proyektor lama.
Widescreen 16 : 9 Laptop, monitor, TV, dan proyektor modern.
Custom Sesuai kebutuhan Poster, infografis, banner, dan kebutuhan khusus.

Custom Slide Size

Design → Slide Size → Custom Slide Size

Pengguna dapat mengatur:

  • Width — lebar slide.
  • Height — tinggi slide.
  • Orientation — orientasi slide.

8. Membuat dan Memasukkan Text Box

Text Box digunakan untuk menempatkan teks secara bebas pada area slide.

Insert → Text Box

Langkah-langkah

  1. Klik tab Insert.
  2. Pilih Text Box.
  3. Klik pada area slide.
  4. Ketik teks.
💡 Text Box dapat digunakan untuk:
  • Keterangan gambar.
  • Kutipan.
  • Informasi tambahan.
  • Label.
  • Teks pada posisi tertentu.

9. Mengubah Jenis Huruf

Jenis huruf disebut Font. PowerPoint menyediakan berbagai jenis font yang dapat digunakan untuk memperjelas tampilan presentasi.

Home → Font

Contoh Font

  • Arial
  • Calibri
  • Times New Roman
  • Verdana
  • Tahoma

Cara Mengubah Font

  1. Blok teks.
  2. Klik tab Home.
  3. Pilih jenis font.
  4. Pilih font yang diinginkan.

10. Mengubah Ukuran Huruf

Ukuran huruf disebut Font Size.

Contoh ukuran:

12 pt → 16 pt → 20 pt → 24 pt → 28 pt → 32 pt

Cara Mengubah Ukuran

  1. Blok teks.
  2. Pilih tab Home.
  3. Pilih ukuran font.
  4. Atau ketik ukuran secara manual.

11. Bold, Italic, dan Underline

Format Fungsi Shortcut
Bold Membuat teks menjadi tebal. Ctrl + B
Italic Membuat teks menjadi miring. Ctrl + I
Underline Memberikan garis bawah pada teks. Ctrl + U

12. Menggunakan WordArt

WordArt digunakan untuk membuat teks dengan gaya dekoratif dan efek visual.

Insert → WordArt

Langkah-langkah

  1. Klik tab Insert.
  2. Klik WordArt.
  3. Pilih salah satu gaya.
  4. Ketik teks.
  5. Atur warna, ukuran, dan efek sesuai kebutuhan.
⚠️ Perhatian

Gunakan WordArt secara seperlunya agar presentasi tetap terlihat profesional.

13. Menggunakan Bullet

Bullet digunakan untuk membuat daftar yang tidak membutuhkan urutan tertentu.

Home → Bullets

• Microsoft Word

• Microsoft Excel

• Microsoft PowerPoint

Langkah

  1. Blok teks.
  2. Klik tab Home.
  3. Klik Bullets.
  4. Pilih bentuk bullet.

14. Menggunakan Numbering

Numbering digunakan untuk membuat daftar yang memiliki urutan.

Home → Numbering

1. Membuka PowerPoint.

2. Membuat slide.

3. Menambahkan teks.

4. Menyimpan presentasi.

Bullet vs Numbering

Bullet Numbering
Tidak menunjukkan urutan. Menunjukkan urutan.
Cocok untuk daftar informasi. Cocok untuk langkah atau prosedur.

15. Mengatur Line Spacing

Line Spacing digunakan untuk mengatur jarak antarbaris pada sebuah paragraf.

Home → Line Spacing

Contoh Jarak

  • 1.0
  • 1.15
  • 1.5
  • 2.0

Langkah

  1. Blok paragraf.
  2. Klik tab Home.
  3. Klik Line Spacing.
  4. Pilih jarak yang diinginkan.

16. Mengatur Indent

Indent digunakan untuk mengatur posisi teks atau paragraf dari batas kiri.

• Materi PowerPoint

◦ Membuat slide

◦ Mengatur layout

◦ Memformat teks

Cara Mengatur Indent

  1. Pilih paragraf.
  2. Klik tab Home.
  3. Gunakan Increase List Level atau Decrease List Level.
💡 Tips:

Indent sangat berguna untuk membuat sub-poin pada Bullet maupun Numbering.
