Fungsi Statistik Microsoft Excel

Progress Pembelajaran Modul 6

1. Pengenalan Fungsi Statistik

Fungsi statistik pada Microsoft Excel digunakan untuk mengolah, menganalisis, dan merangkum sekumpulan data sehingga informasi dari data tersebut dapat lebih mudah dipahami.

Dalam pekerjaan administrasi, fungsi statistik sangat sering digunakan untuk mengolah data peserta, nilai pelatihan, absensi, penjualan, stok, laporan keuangan, dan berbagai jenis data lainnya.

💡 Tujuan pembelajaran

Setelah mempelajari modul ini, peserta diharapkan mampu menggunakan fungsi statistik dasar dan beberapa fungsi statistik lanjutan untuk mengolah data menggunakan Microsoft Excel.

2. Data Contoh

Agar lebih mudah memahami fungsi statistik, gunakan contoh data nilai peserta berikut:

No Nama Program Nilai Status
1 Andi Excel 85 Lulus
2 Budi Excel 78 Lulus
3 Citra Excel 92 Lulus
4 Deni Word 68 Belum Lulus
5 Eka Excel 75 Lulus
6 Fajar Word 88 Lulus
7 Gina Excel 95 Lulus
8 Hadi Word 70 Belum Lulus

Misalnya data nilai berada pada range D2:D9.

3. Fungsi MIN

Fungsi MIN digunakan untuk mencari nilai terkecil dari sekumpulan data.

Sintaks

=MIN(number1,number2,...)

Contoh

=MIN(D2:D9)

Hasilnya adalah 68, karena 68 merupakan nilai paling rendah pada data tersebut.

💡 Tips: MIN sangat berguna untuk mengetahui nilai terendah, harga terendah, jumlah stok terendah, atau pencapaian minimum.

4. Fungsi MAX

Fungsi MAX digunakan untuk mencari nilai terbesar dari suatu kumpulan data.

Sintaks

=MAX(number1,number2,...)

Contoh

=MAX(D2:D9)

Hasilnya adalah 95.

5. Fungsi COUNT

COUNT digunakan untuk menghitung jumlah cell yang berisi angka.

Contoh

=COUNT(D2:D9)

Pada data contoh terdapat 8 nilai angka sehingga hasilnya adalah 8.

⚠️ Perhatikan:

COUNT hanya menghitung data berupa angka. Data berupa teks tidak dihitung.

6. Fungsi COUNTA

COUNTA digunakan untuk menghitung jumlah cell yang tidak kosong.

=COUNTA(B2:B9)

Jika seluruh nama peserta terisi, hasilnya adalah 8.

Perbedaan COUNT dan COUNTA

Fungsi Yang dihitung
COUNT Cell yang berisi angka
COUNTA Cell yang tidak kosong

7. Fungsi COUNTBLANK

COUNTBLANK digunakan untuk menghitung jumlah cell yang kosong.

=COUNTBLANK(B2:B20)

Fungsi ini sangat berguna untuk memeriksa kelengkapan data administrasi.

8. Fungsi COUNTIF

COUNTIF digunakan untuk menghitung jumlah data yang memenuhi satu kriteria tertentu.

Sintaks

=COUNTIF(range,criteria)

Contoh 1 — Menghitung peserta Excel

=COUNTIF(C2:C9,"Excel")

Formula tersebut menghitung jumlah peserta yang memiliki program Excel.

Contoh 2 — Menghitung nilai minimal 80

=COUNTIF(D2:D9,">=80")

Formula tersebut menghitung berapa peserta yang memperoleh nilai minimal 80.

9. Fungsi COUNTIFS

COUNTIFS digunakan untuk menghitung jumlah data yang memenuhi lebih dari satu kriteria.

Sintaks

=COUNTIFS(range1,criteria1,range2,criteria2,...)

Contoh

Menghitung peserta program Excel dengan nilai minimal 80:

=COUNTIFS(C2:C9,"Excel",D2:D9,">=80")
Perbedaan:
  • COUNTIF → satu atau satu jenis kriteria.
  • COUNTIFS → dua atau lebih kriteria.

10. Fungsi AVERAGE

AVERAGE digunakan untuk menghitung nilai rata-rata dari sekumpulan angka.

Sintaks

=AVERAGE(number1,number2,...)

Contoh

=AVERAGE(D2:D9)

Hasilnya merupakan rata-rata seluruh nilai peserta.

💡 Penggunaan:

AVERAGE banyak digunakan untuk menghitung rata-rata nilai, rata-rata penjualan, rata-rata kehadiran, dan rata-rata produktivitas.

11. Fungsi AVERAGEIF

AVERAGEIF digunakan untuk menghitung rata-rata berdasarkan satu kriteria.

Sintaks

=AVERAGEIF(range,criteria,average_range)

Contoh

Menghitung rata-rata nilai peserta program Excel:

=AVERAGEIF(C2:C9,"Excel",D2:D9)

Excel akan mengambil nilai pada kolom D hanya untuk peserta yang programnya adalah Excel.

12. Fungsi AVERAGEIFS

AVERAGEIFS digunakan untuk menghitung rata-rata berdasarkan beberapa kriteria.

Sintaks

=AVERAGEIFS(average_range,criteria_range1,criteria1,...)

Contoh

Misalnya ingin menghitung rata-rata nilai peserta program Excel yang memperoleh nilai minimal 80:

=AVERAGEIFS(D2:D9,C2:C9,"Excel",D2:D9,">=80")

13. Fungsi RANK

Fungsi RANK digunakan untuk menentukan peringkat suatu angka dibandingkan dengan kumpulan angka lainnya.

Sintaks

=RANK(number,ref,[order])

Parameter order menentukan urutan peringkat.

  • 0 atau dikosongkan → nilai terbesar mendapat peringkat 1.
  • 1 → nilai terkecil mendapat peringkat 1.

Contoh

Jika nilai Andi berada di D2 dan seluruh nilai berada di D2:D9:

=RANK(D2,$D$2:$D$9,0)

Formula tersebut menentukan peringkat Andi berdasarkan nilai terbesar sebagai peringkat pertama.

14. Fungsi RANK.EQ

Pada Excel versi yang lebih baru, fungsi RANK.EQ dapat digunakan untuk menentukan peringkat sebuah angka.

=RANK.EQ(D2,$D$2:$D$9,0)
Catatan untuk Excel 2016:

RANK masih dapat digunakan dan sangat umum ditemukan pada file Excel lama. RANK.EQ merupakan pengembangan nama fungsi untuk penentuan peringkat.

15. Fungsi LARGE

LARGE digunakan untuk mengambil nilai terbesar ke-n dari suatu range.

Contoh

Nilai terbesar pertama:

=LARGE(D2:D9,1)

Nilai terbesar kedua:

=LARGE(D2:D9,2)

Nilai terbesar ketiga:

=LARGE(D2:D9,3)

16. Fungsi SMALL

SMALL digunakan untuk mengambil nilai terkecil ke-n dari suatu range.

Contoh

Nilai terkecil pertama:

=SMALL(D2:D9,1)

Nilai terkecil kedua:

=SMALL(D2:D9,2)

17. Fungsi MEDIAN

MEDIAN digunakan untuk mencari nilai tengah dari sekumpulan angka setelah data diurutkan.

Contoh

=MEDIAN(D2:D9)
💡 Kapan menggunakan MEDIAN?

MEDIAN berguna ketika terdapat data yang memiliki nilai ekstrem dan kita ingin mengetahui nilai tengah yang lebih representatif dibandingkan rata-rata.

18. Fungsi MODE

Fungsi MODE digunakan untuk mencari nilai yang paling sering muncul dalam suatu kumpulan data.

=MODE.SNGL(D2:D9)

Pada Excel versi lama, fungsi MODE juga dapat digunakan.

19. Fungsi SUM sebagai Fungsi Statistik Dasar

Walaupun SUM lebih dikenal sebagai fungsi matematika, fungsi ini juga sangat sering digunakan dalam pengolahan data statistik sederhana.

=SUM(D2:D9)

Formula tersebut menghitung jumlah seluruh nilai pada range D2:D9.

20. Ringkasan Fungsi Statistik

Fungsi Kegunaan Contoh
MIN Mencari nilai terkecil =MIN(D2:D9)
MAX Mencari nilai terbesar =MAX(D2:D9)
COUNT Menghitung cell berisi angka =COUNT(D2:D9)
COUNTA Menghitung cell tidak kosong =COUNTA(B2:B9)
COUNTBLANK Menghitung cell kosong =COUNTBLANK(B2:B20)
COUNTIF Menghitung berdasarkan satu kriteria =COUNTIF(C2:C9,"Excel")
COUNTIFS Menghitung berdasarkan beberapa kriteria =COUNTIFS(C2:C9,"Excel",D2:D9,">=80")
AVERAGE Menghitung rata-rata =AVERAGE(D2:D9)
AVERAGEIF Rata-rata dengan satu kriteria =AVERAGEIF(C2:C9,"Excel",D2:D9)
AVERAGEIFS Rata-rata dengan beberapa kriteria =AVERAGEIFS(...)
RANK Menentukan peringkat =RANK(D2,$D$2:$D$9,0)
RANK.EQ Menentukan peringkat =RANK.EQ(D2,$D$2:$D$9,0)
LARGE Mencari nilai terbesar ke-n =LARGE(D2:D9,2)
SMALL Mencari nilai terkecil ke-n =SMALL(D2:D9,2)
MEDIAN Mencari nilai tengah =MEDIAN(D2:D9)
MODE Mencari nilai yang paling sering muncul =MODE.SNGL(D2:D9)

21. Latihan Mandiri

Gunakan data peserta pada modul ini untuk mencoba pertanyaan berikut di Microsoft Excel.

  1. Cari nilai terendah menggunakan fungsi MIN.
  2. Cari nilai tertinggi menggunakan fungsi MAX.
  3. Hitung jumlah peserta menggunakan COUNTA.
  4. Hitung jumlah peserta yang mendapatkan nilai minimal 80 menggunakan COUNTIF.
  5. Hitung jumlah peserta program Excel yang mendapatkan nilai minimal 80 menggunakan COUNTIFS.
  6. Hitung rata-rata seluruh peserta menggunakan AVERAGE.
  7. Hitung rata-rata nilai peserta program Excel menggunakan AVERAGEIF.
  8. Tentukan peringkat masing-masing peserta menggunakan RANK.
  9. Cari nilai tertinggi kedua menggunakan LARGE.
  10. Cari nilai terendah kedua menggunakan SMALL.
🎯 Tantangan:

Buatlah tabel baru yang menampilkan: Nama Peserta, Nilai, dan Peringkat. Kemudian urutkan berdasarkan peringkat terbaik.

22. Kesimpulan

Fungsi statistik merupakan bagian penting dalam pengolahan data menggunakan Microsoft Excel.

Dengan menguasai fungsi seperti MIN, MAX, COUNT, COUNTA, COUNTIF, COUNTIFS, AVERAGE, AVERAGEIF, RANK, LARGE, SMALL, MEDIAN dan fungsi sejenis lainnya, peserta dapat melakukan analisis data secara lebih cepat dan akurat.

📌 Fokus yang harus dikuasai:
  • Membedakan COUNT dan COUNTA.
  • Memahami penggunaan COUNTIF dan COUNTIFS.
  • Memahami AVERAGE dan AVERAGEIF.
  • Menggunakan RANK untuk menentukan peringkat.
  • Menggunakan LARGE dan SMALL untuk mengambil nilai ke-n.
  • Menggunakan MIN dan MAX untuk mengetahui nilai ekstrem.
