Modul 3

Menyisipkan Objek pada Microsoft PowerPoint 2016

📚 Tentang Modul

Pada modul ini peserta akan mempelajari cara menyisipkan berbagai objek ke dalam slide Microsoft PowerPoint 2016.

Objek dapat digunakan untuk membuat presentasi lebih informatif, menarik, interaktif, dan profesional.

🖼️
Picture Gambar dari komputer
🌐
Online Picture Gambar online
🔷
Shapes Bentuk dan diagram
⭐
Icons Simbol visual
🔄
SmartArt Diagram informasi
📈
Chart Grafik data
📋
Table Data baris dan kolom
📸
Screenshot Tangkapan layar
🔗
Hyperlink Tautan

🎯 Tujuan Pembelajaran

Setelah menyelesaikan modul ini, peserta diharapkan mampu:

  1. Menyisipkan Picture.
  2. Menyisipkan Online Picture.
  3. Menggunakan Shapes.
  4. Menyisipkan Icons.
  5. Membuat SmartArt.
  6. Membuat Chart.
  7. Membuat dan mengatur Table.
  8. Menggunakan Screenshot.
  9. Membuat Hyperlink.
  10. Menggunakan Action Buttons.
  11. Mengatur Header dan Footer.
  12. Menampilkan Date and Time.
  13. Menampilkan Slide Number.
1

Picture

Picture digunakan untuk memasukkan gambar dari komputer ke dalam slide.

Insert → Pictures → This Device

Langkah-langkah

1
Klik tab Insert.
2
Pilih Pictures.
3
Pilih This Device.
4
Cari dan pilih gambar.
5
Klik Insert.

Mengatur Gambar

Setelah gambar dipilih, gunakan menu:

Picture Tools → Format
  • Crop
  • Corrections
  • Color
  • Artistic Effects
  • Picture Styles
  • Picture Border
  • Picture Effects
  • Rotate
  • Compress Pictures
💡 Tips:

Gunakan gambar dengan resolusi yang baik agar gambar tidak terlihat pecah ketika ditampilkan pada layar besar.

2

Online Picture

Online Picture digunakan untuk mencari dan memasukkan gambar dari sumber online.

Insert → Online Pictures

Langkah-langkah

  1. Klik Insert.
  2. Pilih Online Pictures.
  3. Ketik kata kunci pencarian.
  4. Pilih gambar.
  5. Klik Insert.
Contoh kata kunci

Microsoft Office Training

Computer Training

⚠️ Perhatian:

Perhatikan hak penggunaan gambar. Untuk publikasi atau penggunaan komersial, gunakan gambar yang memiliki izin yang sesuai.

3

Shapes

Shapes adalah bentuk-bentuk siap pakai yang dapat digunakan untuk membuat diagram, tombol, ilustrasi, maupun penanda.

Insert → Shapes

Contoh Shapes

  • Rectangle
  • Rounded Rectangle
  • Oval
  • Triangle
  • Arrow
  • Line
  • Callout
  • Flowchart

Penggunaan Shapes

➡️
Diagram Alur
🔘
Tombol
📦
Kotak Informasi
📍
Penanda

Mengatur Shapes

Drawing Tools → Format
  • Shape Fill
  • Shape Outline
  • Shape Effects
  • Shape Style
  • Rotate
  • Align
4

Icons

Icons merupakan simbol grafis yang dapat digunakan untuk memperjelas informasi pada slide.

Insert → Icons
📌 Catatan PowerPoint 2016

Fitur Icons dapat berbeda ketersediaannya tergantung edisi dan versi pembaruan Microsoft Office yang digunakan.

Contoh Penggunaan

  • 💻 Komputer
  • 📊 Data
  • 📁 File
  • 👥 Peserta
  • 📅 Jadwal
  • 📍 Lokasi
💡 Manfaat:

Ikon dapat membuat slide lebih mudah dipahami tanpa menggunakan terlalu banyak teks.

5

SmartArt

SmartArt digunakan untuk membuat informasi dalam bentuk diagram visual.

Insert → SmartArt

Kategori SmartArt

  • List
  • Process
  • Cycle
  • Hierarchy
  • Relationship
  • Matrix
  • Pyramid
Contoh SmartArt Process

Pendaftaran → Seleksi → Pelatihan → Evaluasi → Kelulusan

Mengatur SmartArt

Gunakan:

SmartArt Tools → Design

dan:

SmartArt Tools → Format
  • Mengubah warna.
  • Mengubah SmartArt Style.
  • Menambah Shape.
  • Menghapus Shape.
  • Mengubah Layout.
  • Mengatur ukuran.
6

Chart

Chart digunakan untuk menyajikan data dalam bentuk grafik sehingga data lebih mudah dibandingkan dan dipahami.

Insert → Chart

Jenis Chart

Jenis Chart Penggunaan
Column Membandingkan data.
Bar Membandingkan data secara horizontal.
Line Melihat perkembangan data.
Pie Melihat persentase.
Area Menampilkan perubahan data.
Scatter Menampilkan hubungan antar-data.

Contoh Data

Program Peserta
TIK 20
Bisnis & Manajemen 25
Teknik Las 18
Garmen 22
7

Table

Table digunakan untuk menyajikan data dalam bentuk baris dan kolom.

Insert → Table

Contoh

No Nama Program Nilai
1 Andi TIK 85
2 Budi Las 88
3 Citra Garmen 90

Mengatur Table

Table Tools → Design
Table Tools → Layout
  • Mengubah warna.
  • Menambah baris.
  • Menghapus baris.
  • Menggabungkan cell.
  • Mengatur ukuran kolom.
  • Mengatur posisi teks.
8

Screenshot

Screenshot digunakan untuk mengambil gambar dari jendela aplikasi yang sedang terbuka dan memasukkannya ke PowerPoint.

Insert → Screenshot

Available Windows

Digunakan untuk mengambil gambar dari jendela aplikasi yang sedang terbuka.

Screen Clipping

Digunakan untuk memilih bagian tertentu dari layar.

💡 Contoh penggunaan:
  • Membuat tutorial komputer.
  • Menjelaskan langkah penggunaan software.
  • Menampilkan halaman website.
  • Menunjukkan hasil pengaturan aplikasi.

Hyperlink

Hyperlink digunakan untuk membuat teks atau objek dapat diklik dan mengarah ke lokasi tertentu.

Insert → Hyperlink

Ctrl + K

Hyperlink dapat mengarah ke:

  • Website.
  • File.
  • Email.
  • Slide tertentu.

📚 Materi 2

📝 Latihan

10

Action Buttons

Action Buttons merupakan tombol yang dapat diberikan tindakan tertentu ketika diklik.

Insert → Shapes → Action Buttons

Contoh Action Button

🏠
Home Menu utama
◀️
Back Slide sebelumnya
▶️
Next Slide berikutnya
❌
Exit Keluar

Action Settings

Action Button dapat diarahkan ke:

  • Next Slide
  • Previous Slide
  • First Slide
  • Last Slide
  • Hyperlink
  • Run Program
💡 Manfaat:

Action Button dapat digunakan untuk membuat media pembelajaran PowerPoint yang interaktif.

11

Header and Footer

Header dan Footer digunakan untuk memberikan informasi tambahan pada slide.

Insert → Header & Footer

Informasi yang dapat ditampilkan

  • Date and Time
  • Slide Number
  • Footer

Langkah-langkah

  1. Klik tab Insert.
  2. Pilih Header & Footer.
  3. Centang informasi yang ingin ditampilkan.
  4. Klik Apply.
  5. Atau klik Apply to All.
12

Date and Time

Date and Time digunakan untuk menampilkan tanggal dan waktu pada slide.

Insert → Header & Footer → Date and Time

Jenis Pengaturan

Pengaturan Fungsi
Update automatically Tanggal diperbarui secara otomatis.
Fixed Tanggal tetap sesuai tanggal yang dimasukkan.
💡 Penggunaan:

Cocok digunakan untuk presentasi rapat, pelatihan, seminar, laporan, dan presentasi kegiatan.

13

Slide Number

Slide Number digunakan untuk menampilkan nomor halaman slide.

Insert → Header & Footer → Slide Number

Langkah-langkah

  1. Klik Insert.
  2. Pilih Header & Footer.
  3. Centang Slide number.
  4. Klik Apply to All.
Contoh

Slide 1 → 1

Slide 2 → 2

Slide 3 → 3

Slide 4 → 4

💡 Manfaat:

Nomor slide membantu audiens mengetahui posisi mereka dalam sebuah presentasi.

🛠️ Praktik Modul 3

Buat sebuah presentasi dengan tema:

"Profil dan Program Pelatihan BLK"

Slide 1 — Cover

Masukkan:

  • Judul.
  • Picture.
  • WordArt atau Text Box.

Slide 2 — Profil

Gunakan:

  • Picture.
  • Shapes.
  • Text Box.

Slide 3 — Program Pelatihan

Gunakan SmartArt.

Contoh:

TIK → Bisnis & Manajemen → Teknik → Garmen

Slide 4 — Data Peserta

Buat tabel menggunakan:

Insert → Table

Minimal 4 kolom dan 5 baris.

Slide 5 — Grafik

Masukkan data peserta menggunakan:

Insert → Chart

Gunakan jenis Column Chart.

Slide 6 — Screenshot

Masukkan screenshot halaman website atau aplikasi menggunakan:

Insert → Screenshot

Slide 7 — Navigasi

Buat tombol:

  • 🏠 Home
  • ◀ Back
  • ▶ Next

Gunakan Action Buttons dan hyperlink untuk navigasi antar-slide.

Slide 8 — Penutup

Masukkan:

  • Date and Time.
  • Slide Number.
  • Footer.

Contoh Footer:
