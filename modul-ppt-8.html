MODUL 8

Mencetak dan Export Presentasi

Microsoft PowerPoint 2016

📚 Tentang Modul

Modul 8 merupakan modul terakhir dalam pembelajaran Microsoft PowerPoint 2016. Pada modul ini peserta akan mempelajari tahap akhir pengolahan presentasi, yaitu mencetak, menyimpan, dan melakukan export presentasi ke berbagai format.

🎯 Tujuan Pembelajaran
  • Peserta mampu mencetak presentasi dengan pengaturan yang tepat.
  • Peserta mampu membuat handout presentasi.
  • Peserta mampu memilih ukuran dan orientasi kertas.
  • Peserta mampu menyimpan presentasi dalam berbagai format.
  • Peserta mampu melakukan export presentasi menjadi PDF.
  • Peserta mampu membuat video dari presentasi.
  • Peserta mampu menyimpan slide sebagai gambar.

1️⃣ Mencetak Presentasi

Fitur Print digunakan untuk mencetak slide presentasi ke dalam bentuk dokumen fisik.

Menu pencetakan dapat dibuka melalui:

File → Print

Langkah Mencetak Presentasi

1
Klik menu File.
2
Pilih Print.
3
Pilih printer yang akan digunakan.
4
Tentukan jumlah salinan pada bagian Copies.
5
Tentukan slide yang ingin dicetak.
6
Periksa hasil melalui Print Preview.
7
Klik Print.

2️⃣ Pilihan Slide yang Dicetak

PowerPoint 2016 menyediakan beberapa pilihan slide yang akan dicetak.

Pilihan Fungsi
Print All Slides Mencetak seluruh slide dalam presentasi.
Print Selection Mencetak bagian slide yang dipilih.
Print Current Slide Mencetak slide yang sedang aktif.
Custom Range Mencetak slide berdasarkan nomor atau rentang tertentu.

3️⃣ Print Layout

PowerPoint menyediakan beberapa pilihan layout ketika presentasi akan dicetak.

Full Page Slides

Setiap slide dicetak dalam satu halaman penuh. Pilihan ini cocok ketika slide ingin dicetak sebagai dokumen presentasi.

Notes Pages

Notes Pages mencetak slide beserta catatan presenter yang terdapat pada slide tersebut.

Outline

Outline mencetak struktur teks utama dari presentasi.

Handouts

Handouts digunakan untuk mencetak beberapa slide dalam satu halaman sehingga lebih hemat kertas dan cocok dibagikan kepada peserta.

4️⃣ Mencetak Handout

Handout merupakan versi cetak presentasi yang dirancang agar dapat dibagikan kepada audiens sebagai bahan referensi.

Pilihan Keterangan
1 Slide Satu slide dalam satu halaman.
2 Slides Dua slide dalam satu halaman.
3 Slides Tiga slide dengan area catatan.
4 Slides Empat slide dalam satu halaman.
6 Slides Enam slide dalam satu halaman.
9 Slides Sembilan slide dalam satu halaman.
💡 Tips: Untuk bahan pelatihan, pilihan 3 Slides sering berguna karena menyediakan ruang bagi peserta untuk membuat catatan.

5️⃣ Pengaturan Warna dan Kertas

Color

Mencetak presentasi menggunakan warna asli dari slide.

Grayscale

Mencetak presentasi dalam bentuk abu-abu. Pilihan ini dapat menghemat tinta warna.

Pure Black and White

Mencetak menggunakan warna hitam dan putih secara sederhana.

Ukuran dan Orientasi Kertas

Sebelum mencetak, periksa ukuran kertas dan orientasinya agar hasil cetak sesuai kebutuhan.

  • Portrait
  • Landscape
  • Ukuran kertas sesuai printer

6️⃣ Menyimpan Presentasi

PowerPoint dapat menyimpan presentasi dalam berbagai format sesuai kebutuhan.

PPTX
.pptx

Format standar Microsoft PowerPoint.

PPT
.ppt

Format kompatibilitas untuk PowerPoint versi lama.

PDF
.pdf

Cocok untuk dibagikan dan dicetak.

PPSX
.ppsx

File yang dapat langsung dibuka dalam mode Slide Show.

POTX
.potx

Format template PowerPoint.

7️⃣ Export Presentasi

Fitur Export digunakan untuk mengubah presentasi menjadi format lain sesuai kebutuhan.

Menu Export dapat dibuka melalui:

File → Export

Beberapa pilihan export yang tersedia antara lain:

  • Create PDF/XPS
  • Create a Video
  • Package Presentation for CD
  • Create Handouts

8️⃣ Export ke PDF

PDF merupakan salah satu format paling praktis untuk membagikan presentasi karena tampilan dokumen relatif tetap ketika dibuka pada perangkat yang berbeda.

Langkah Export PDF

1
Klik File.
2
Pilih Export.
3
Pilih Create PDF/XPS.
4
Tentukan nama dan lokasi file.
5
Klik Publish.
✅ PDF dapat digunakan untuk membagikan materi, mengarsipkan presentasi, maupun mencetak dokumen.

9️⃣ Membuat Video dari Presentasi

PowerPoint 2016 dapat digunakan untuk membuat video berdasarkan isi presentasi.

Menu yang digunakan:

File → Export → Create a Video

Pengaturan Video

  • Menentukan kualitas video.
  • Menggunakan recorded timings and narrations.
  • Mengatur durasi setiap slide.
  • Menyimpan hasil sebagai file video.
💡 Jika presentasi memiliki narasi atau timing, pastikan semuanya sudah diuji terlebih dahulu sebelum membuat video.

🔟 Menyimpan Slide sebagai Gambar

Setiap slide PowerPoint juga dapat disimpan sebagai file gambar.

Format gambar yang dapat digunakan antara lain:

  • JPEG
  • PNG
  • GIF
  • TIFF
  • BMP

Current Slide

Hanya slide yang sedang dipilih yang akan disimpan sebagai gambar.

Every Slide

Seluruh slide dalam presentasi akan disimpan sebagai gambar secara terpisah.

1️⃣1️⃣ Package Presentation for CD

Fitur Package Presentation for CD digunakan untuk mengumpulkan presentasi beserta file pendukung yang dibutuhkan.

Fitur ini berguna ketika presentasi akan dipindahkan ke komputer lain sehingga file pendukung lebih mudah dikumpulkan.

📦 Tujuan utama fitur ini adalah membantu mempersiapkan presentasi agar lebih mudah dipindahkan atau didistribusikan.

1️⃣2️⃣ Memilih Format Sesuai Kebutuhan

Kebutuhan Format
Mengedit kembali presentasi .pptx
Dibagikan dan dicetak .pdf
Langsung menjalankan Slide Show .ppsx
Membuat template .potx
Membuat video Video
Menyimpan slide sebagai gambar .jpg / .png

🛠️ Praktik Modul 8

Gunakan presentasi yang telah dibuat pada modul sebelumnya kemudian lakukan praktik berikut:

  1. Cetak satu slide dalam satu halaman.
  2. Cetak presentasi menggunakan pilihan 3 Slides Handouts.
  3. Coba mencetak menggunakan mode Grayscale.
  4. Simpan presentasi dalam format .pptx.
  5. Export presentasi menjadi PDF.
  6. Simpan salah satu slide menjadi PNG atau JPG.
  7. Coba buat presentasi menjadi video.
  8. Bandingkan hasil setiap format.
🎯 Target Praktik: Peserta mampu memilih metode pencetakan dan format export yang sesuai dengan kebutuhan penggunaan presentasi.

📌 Rangkuman Modul 8

  • Menu File → Print digunakan untuk mencetak presentasi.
  • Presentasi dapat dicetak sebagai Full Page, Notes Pages, Outline, maupun Handouts.
  • Handouts dapat digunakan sebagai bahan yang dibagikan kepada peserta.
  • Presentasi dapat disimpan dalam berbagai format seperti PPTX, PPT, PDF, PPSX dan POTX.
  • Menu File → Export digunakan untuk mengubah presentasi ke format lain.
  • Presentasi dapat di-export menjadi PDF.
  • Presentasi dapat dibuat menjadi video.
  • Slide dapat disimpan sebagai file gambar.
  • Format output harus dipilih sesuai kebutuhan.

🏆 Kompetensi Akhir Microsoft PowerPoint 2016

Setelah menyelesaikan Modul 1 sampai Modul 8, peserta diharapkan mampu membuat presentasi menggunakan Microsoft PowerPoint 2016 mulai dari tahap pembuatan hingga menghasilkan file yang siap digunakan, dicetak, maupun didistribusikan.

Peserta mampu:
  • Membuat dan mengelola slide.
  • Mengatur desain presentasi.
  • Menyisipkan berbagai objek.
  • Membuat diagram dan grafik.
  • Menggunakan audio, video dan animasi.
  • Menggunakan transition dan Slide Show.
  • Melakukan review presentasi.
  • Mencetak dan melakukan export presentasi.
