MODUL 5

📊 Tabel, Gambar, dan Objek Profesional

Microsoft Word 2016

Pada modul ini peserta akan mempelajari cara membuat dan mengelola tabel, menyisipkan gambar, menggunakan Shape dan Text Box, serta menggabungkan berbagai objek untuk membuat dokumen yang lebih profesional.

🎯 Tujuan Pembelajaran

Setelah menyelesaikan Modul 5, peserta mampu:

  1. Membuat dan mengelola tabel.
  2. Menggabungkan dan memisahkan sel.
  3. Mengatur struktur tabel.
  4. Mengolah data di dalam tabel.
  5. Menyisipkan gambar ke dalam dokumen.
  6. Mengatur posisi gambar terhadap teks.
  7. Membuat dan mengatur Shape.
  8. Menggunakan Text Box.
  9. Mengatur beberapa objek dalam satu dokumen.
  10. Membuat dokumen administrasi yang menggabungkan teks, tabel, gambar, dan objek.

1. Membuat Tabel

Tabel digunakan untuk menyajikan informasi secara terstruktur dalam bentuk baris dan kolom.

Dalam pekerjaan administrasi, tabel sering digunakan untuk membuat:

  • Daftar peserta
  • Daftar nilai
  • Jadwal pelatihan
  • Daftar inventaris
  • Rekap kegiatan
  • Daftar kehadiran

Cara Membuat Tabel

Pilih menu:

Insert → Table

Kemudian tentukan jumlah kolom dan baris yang diperlukan.

2. Menambah dan Menghapus Baris atau Kolom

Struktur tabel dapat diubah setelah tabel dibuat. Kita dapat menambahkan maupun menghapus baris dan kolom sesuai kebutuhan.

Menambah Baris atau Kolom

Klik tabel kemudian pilih:

Table Tools → Layout
  • Insert Above
  • Insert Below
  • Insert Left
  • Insert Right

Menghapus Baris atau Kolom

Gunakan:

Layout → Delete

Kemudian pilih bagian yang ingin dihapus.

3. Merge Cells

Merge Cells digunakan untuk menggabungkan beberapa sel menjadi satu.

Fitur ini sering digunakan untuk membuat judul tabel.

Cara:
  1. Blok sel yang ingin digabung.
  2. Pilih Table Tools → Layout.
  3. Klik Merge Cells.

4. Split Cells

Split Cells digunakan untuk membagi satu sel menjadi beberapa sel.

Layout → Split Cells

Tentukan jumlah kolom dan baris yang diinginkan.

5. Mengatur Posisi Isi Tabel

Isi tabel dapat diatur secara horizontal maupun vertikal.

Contoh:

  • Nama → rata kiri
  • Nomor → rata tengah
  • Nilai → rata tengah
  • Judul tabel → rata tengah
Table Tools → Layout → Alignment

6. Mengubah Data Menjadi Tabel

Microsoft Word dapat mengubah data teks menjadi tabel secara otomatis.

Contoh data:

No Nama Program Nilai
1 Andi TIK 85
2 Budi TIK 90

Data tersebut dapat dibuat menjadi tabel menggunakan:

Insert → Table → Convert Text to Table

7. Menyisipkan Gambar

Gambar dapat digunakan untuk memperkuat informasi dalam sebuah dokumen.

Contohnya:

  • Logo instansi
  • Foto kegiatan
  • Foto peserta
  • Dokumentasi
  • Ilustrasi
Insert → Pictures

8. Mengatur Posisi Gambar terhadap Teks

Setelah gambar dimasukkan, posisi gambar dapat diatur agar teks dapat berada di sekitar gambar.

Picture Format → Wrap Text
  • In Line with Text
  • Square
  • Tight
  • Top and Bottom
  • Behind Text
  • In Front of Text
💡 Tips:

Untuk membuat teks berada di samping gambar, pilihan Square biasanya paling mudah digunakan.

9. Membuat Shape

Shape dapat digunakan untuk membuat elemen visual dalam dokumen.

Insert → Shapes

Contoh Shape:

  • Rectangle
  • Circle
  • Arrow
  • Line
  • Callout

Shape dapat digunakan untuk membuat diagram, kotak informasi, panah, dan ilustrasi sederhana.

10. Text Box

Text Box digunakan untuk menempatkan teks pada area tertentu secara lebih fleksibel.

Insert → Text Box

Text Box dapat digunakan untuk:

  • Informasi penting
  • Catatan
  • Keterangan gambar
  • Identitas
  • Highlight informasi

11. Mengatur Beberapa Objek

Jika dokumen memiliki beberapa objek seperti gambar, Shape, dan Text Box, objek tersebut dapat diatur agar posisinya lebih rapi.

Beberapa fitur yang dapat digunakan:

  • Bring Forward
  • Send Backward
  • Bring to Front
  • Send to Back
  • Align
  • Group
Group

Fitur Group memungkinkan beberapa objek diperlakukan sebagai satu objek sehingga lebih mudah dipindahkan atau diatur.

12. Membuat Dokumen Gabungan

Pada tahap ini peserta menggabungkan beberapa kemampuan untuk menghasilkan dokumen yang lebih kompleks.

Contoh: Laporan Kegiatan Pelatihan

Dokumen dapat berisi:

  1. Judul kegiatan
  2. Identitas kegiatan
  3. Foto kegiatan
  4. Tabel peserta
  5. Kotak informasi menggunakan Text Box
  6. Diagram sederhana menggunakan Shape
💡 Tujuan:

Peserta tidak hanya memahami fungsi setiap fitur, tetapi mampu menggabungkan beberapa fitur untuk membuat dokumen administrasi yang siap digunakan.

🏆 Latihan Praktik Modul 5

Membuat Laporan Kegiatan Pelatihan TIK

Buat sebuah dokumen dengan judul:

LAPORAN KEGIATAN PELATIHAN TIK

Dokumen wajib memiliki:

  1. Judul kegiatan.
  2. Satu foto kegiatan.
  3. Tabel minimal 10 peserta.
  4. Merge Cells pada judul tabel.
  5. Pengaturan alignment isi tabel.
  6. Satu Text Box untuk informasi penting.
  7. Minimal dua Shape.
  8. Minimal satu penggunaan Wrap Text.
  9. Beberapa objek diatur menggunakan Align atau Group.

🎯 Hasil Akhir

Dokumen harus terlihat seperti laporan kegiatan yang siap digunakan, bukan sekadar latihan fitur Microsoft Word.
