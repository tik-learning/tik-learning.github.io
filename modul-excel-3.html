Format Cell

Memahami Type Data, Format Data, Format Cell, Number Custom, dan Custom Format dengan Kondisi Warna

🎯 Tujuan Pembelajaran

Setelah menyelesaikan Modul 3, peserta diharapkan mampu memahami dan menggunakan fitur Format Cell pada Microsoft Excel.

Kompetensi yang dipelajari:
  • Mengenali berbagai type data Excel.
  • Memahami perbedaan type data dan format data.
  • Memahami fungsi Format Cells.
  • Menggunakan Number Custom.
  • Membuat format angka sesuai kebutuhan.
  • Menggunakan kondisi warna pada Custom Format.

1. Type Data dan Format Data

Dalam Microsoft Excel, data yang dimasukkan ke dalam cell dapat memiliki berbagai tipe. Excel akan mencoba mengenali tipe data berdasarkan isi yang dimasukkan.

Type Data yang Umum Digunakan

Type Data Contoh Kegunaan
Text Nama Peserta Data berupa tulisan.
Number 125000 Data angka yang dapat dihitung.
Date 23/08/2026 Data tanggal.
Percentage 85% Data dalam bentuk persentase.
Currency Rp 150.000 Data nominal uang.

Type Data vs Format Data

Type data berkaitan dengan bagaimana Excel mengenali suatu nilai, sedangkan format data mengatur bagaimana nilai tersebut ditampilkan.

Nilai sebenarnya: 150000

Dapat ditampilkan sebagai:
150000
150,000
Rp 150.000
Rp 150,000.00
💡 Ingat: Mengubah format cell biasanya tidak mengubah nilai sebenarnya. Yang berubah terutama adalah cara nilai tersebut ditampilkan.

2. Apa Itu Format Cell?

Format Cell adalah fitur Microsoft Excel yang digunakan untuk mengatur tampilan dan karakteristik isi cell.

Dengan Format Cells, kita dapat mengatur angka, tanggal, alignment, font, border, warna, dan berbagai pengaturan lainnya.

Cara Membuka Format Cells

1
Pilih cell atau range yang ingin diformat.
2
Klik kanan pada cell kemudian pilih Format Cells.
3
Cara cepat menggunakan keyboard: Ctrl + 1.

Bagian Penting Format Cells

Tab Fungsi
Number Mengatur format angka, tanggal, persen, currency, dan Custom.
Alignment Mengatur posisi dan arah teks.
Font Mengatur jenis, ukuran, dan gaya huruf.
Border Mengatur garis pada cell.
Fill Mengatur warna latar belakang cell.
Protection Mengatur perlindungan cell.

3. Format Cell – Number Custom

Custom memungkinkan kita membuat pola tampilan angka sendiri tanpa mengubah nilai asli yang tersimpan dalam cell.

Contoh Custom Format

Custom Format Nilai Tampilan
00000 125 00125
000-000-000 123456789 123-456-789
Rp #,##0 150000 Rp 150,000
0.00 75.5 75.50

Contoh Nomor Peserta

Misalnya nomor peserta disimpan sebagai angka:

Nilai asli:
25

Custom Format:
0000

Hasil tampilan:
0025
⚠️ Perlu diperhatikan bahwa Custom Format hanya mengatur tampilan. Nilai asli cell tetap berupa angka 25, bukan teks 0025.

4. Simbol Penting dalam Custom Format

Simbol Fungsi Contoh
0 Menampilkan angka, termasuk nol. 0000
# Menampilkan angka jika tersedia. #,##0
? Membantu penyelarasan posisi angka. ???.??
, Dapat digunakan sebagai pemisah ribuan sesuai pengaturan lokal. #,##0
. Dapat digunakan untuk desimal sesuai pengaturan lokal. 0.00
"teks" Menampilkan teks tambahan. 0 "unit"

0 "unit"

25

5. Custom Format dengan Kondisi Warna

Custom Number Format juga dapat digunakan untuk memberikan warna berdasarkan kondisi nilai.

Salah satu bentuk format Custom menggunakan beberapa bagian yang dipisahkan dengan tanda titik koma ;.

Contoh Format

[Green]#,##0;[Red]-#,##0;0

Format tersebut dapat digunakan untuk menampilkan nilai positif dengan warna hijau dan nilai negatif dengan warna merah.

Nilai Positif
Hijau
Nilai Negatif
Merah
Nilai Nol
Normal

Contoh Penggunaan

Nilai Makna Warna Tampilan
500000 Nilai positif Hijau
-250000 Nilai negatif Merah
0 Tidak ada nilai perubahan Normal

6. Custom Format Berdasarkan Nilai

Selain warna positif dan negatif, Custom Format juga dapat menggunakan kondisi tertentu.

Contoh Nilai Peserta

[Green][>=75]0;[Red][<75]0

Dengan pola tersebut, nilai 75 atau lebih dapat ditampilkan dengan warna hijau, sedangkan nilai di bawah 75 ditampilkan dengan warna merah.

85
LULUS
75
LULUS
65
BELUM LULUS
💡 Catatan: Custom Format dengan warna berbeda dengan Conditional Formatting. Custom Format mengatur tampilan berdasarkan pola format cell, sedangkan Conditional Formatting merupakan fitur khusus untuk memberikan format berdasarkan aturan/kondisi.

🎯 Tugas:
  1. Buat format nomor menjadi empat digit. Contoh: 0001, 0002, 0003.
  2. Buat format Uang Saku menjadi format Rupiah.
  3. Buat nilai 75 ke atas berwarna hijau.
  4. Buat nilai di bawah 75 berwarna merah.
  5. Buat stok positif berwarna hijau dan stok negatif berwarna merah.

📌 Rangkuman Modul 3

  • Excel memiliki berbagai type data seperti Text, Number, Date, Percentage, dan Currency.
  • Format data menentukan bagaimana nilai ditampilkan pada worksheet.
  • Format Cells dapat dibuka menggunakan Ctrl + 1.
  • Number Custom memungkinkan kita membuat pola tampilan angka sendiri.
  • Simbol 0 dan # memiliki fungsi berbeda dalam Custom Format.
  • Custom Format dapat menggunakan kondisi dan warna untuk membedakan nilai.
  • Custom Format terutama mengubah tampilan, bukan nilai asli yang tersimpan dalam cell.
💡 Kunci pembelajaran:
Jangan hanya memasukkan data ke Excel. Pastikan data juga memiliki format yang tepat agar mudah dibaca, dihitung, dan digunakan dalam laporan.
