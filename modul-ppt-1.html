Modul 1

Mengenal Microsoft PowerPoint 2016

📚 Tentang Modul

Microsoft PowerPoint 2016 merupakan salah satu aplikasi Microsoft Office yang digunakan untuk membuat dan menyampaikan presentasi dalam bentuk slide.

Pada modul pertama ini peserta akan mengenal PowerPoint 2016, mulai dari pengertian, fungsi, manfaat, bagian-bagian tampilan, Ribbon, Tab Menu, hingga pengaturan ukuran dan orientasi slide.

🎯 Tujuan Pembelajaran

Setelah menyelesaikan modul ini, peserta diharapkan mampu:

  • Menjelaskan pengertian Microsoft PowerPoint 2016.
  • Menjelaskan fungsi Microsoft PowerPoint.
  • Menjelaskan manfaat PowerPoint dalam pekerjaan dan pembelajaran.
  • Mengenali bagian-bagian utama PowerPoint 2016.
  • Mengenali Ribbon, Tab Menu, Group dan Command.
  • Mengatur ukuran slide.
  • Mengatur orientasi slide.

1. Pengertian Microsoft PowerPoint 2016

Microsoft PowerPoint 2016 adalah aplikasi pengolah presentasi yang dikembangkan oleh Microsoft dan menjadi bagian dari Microsoft Office 2016.

PowerPoint digunakan untuk membuat materi presentasi dalam bentuk slide yang dapat berisi teks, gambar, tabel, grafik, audio, video, animasi, dan berbagai elemen visual lainnya.

💡 Intinya:

PowerPoint digunakan untuk membantu pengguna menyampaikan informasi atau ide secara visual melalui rangkaian slide.

2. Fungsi Microsoft PowerPoint 2016

PowerPoint memiliki berbagai fungsi, antara lain:

  • Membuat bahan presentasi.
  • Menyajikan informasi secara visual.
  • Membuat materi pembelajaran.
  • Membuat laporan dan proposal.
  • Membuat presentasi bisnis.
  • Membuat media promosi.
  • Menyampaikan data dalam bentuk grafik dan diagram.

3. Manfaat Microsoft PowerPoint 2016

  • Informasi menjadi lebih mudah dipahami.
  • Presentasi menjadi lebih menarik.
  • Materi dapat disusun secara sistematis.
  • Mempermudah penyampaian ide.
  • Mendukung penggunaan gambar, audio, video, dan grafik.
  • Membantu membuat presentasi yang profesional.

4. Bagian-Bagian Microsoft PowerPoint 2016

Sebelum membuat presentasi, penting untuk mengenali bagian utama dari tampilan Microsoft PowerPoint 2016.

Bagian Fungsi
Title Bar Menampilkan nama file dan aplikasi PowerPoint.
Quick Access Toolbar Memberikan akses cepat ke perintah yang sering digunakan.
File Digunakan untuk mengelola file seperti membuat, membuka, menyimpan, dan mencetak.
Ribbon Area yang berisi berbagai perintah PowerPoint.
Tab Menu Mengelompokkan perintah berdasarkan fungsi.
Group Mengelompokkan perintah yang memiliki fungsi sejenis.
Command Tombol atau perintah untuk menjalankan fungsi tertentu.
Thumbnail Pane Menampilkan daftar slide dalam bentuk gambar kecil.
Slide Pane Area utama untuk membuat dan mengedit slide.
Notes Pane Tempat menambahkan catatan untuk presenter.
Status Bar Menampilkan informasi mengenai dokumen dan tampilan.
Zoom Slider Digunakan untuk memperbesar atau memperkecil tampilan slide.

5. Mengenal Ribbon

Ribbon adalah bagian pada Microsoft PowerPoint yang berisi kumpulan perintah untuk mengolah presentasi.

Struktur Ribbon dapat dipahami sebagai:

Tab → Group → Command

Contoh:

Home → Font → Bold

Artinya:

  • Home = Tab
  • Font = Group
  • Bold = Command

6. Mengenal Tab Menu

Tab Menu digunakan untuk mengelompokkan berbagai perintah berdasarkan fungsi.

File

Mengelola file seperti New, Open, Save, Save As, Print, dan Options.

Home

Mengatur teks, paragraf, clipboard, slide, drawing, dan editing.

Insert

Memasukkan gambar, tabel, grafik, bentuk, SmartArt, audio, video, dan objek lainnya.

Design

Mengatur tema, warna, background, dan ukuran slide.

Transitions

Mengatur efek perpindahan dari satu slide ke slide lainnya.

Animations

Memberikan efek animasi pada objek yang terdapat di dalam slide.

Slide Show

Menjalankan dan mengatur tampilan presentasi.

Review

Membantu pemeriksaan, komentar, bahasa, dan fitur review lainnya.

View

Mengatur tampilan dan cara melihat presentasi.

7. Thumbnail Pane dan Slide Pane

Thumbnail Pane

Thumbnail Pane berada di sisi kiri tampilan PowerPoint. Bagian ini menampilkan slide dalam bentuk gambar kecil.

Thumbnail dapat digunakan untuk:

  • Memilih slide.
  • Mengubah urutan slide.
  • Menghapus slide.
  • Menduplikasi slide.

Slide Pane

Slide Pane merupakan area utama tempat pengguna membuat dan mengedit isi slide.

8. Notes Pane

Notes Pane digunakan untuk menambahkan catatan yang membantu presenter ketika menyampaikan materi.

Contoh isi catatan:

  • Poin penting yang harus dijelaskan.
  • Informasi tambahan.
  • Catatan untuk presenter.
  • Penjelasan yang tidak perlu ditampilkan pada slide.

9. Status Bar dan Zoom

Status Bar

Status Bar berada di bagian bawah jendela PowerPoint. Bagian ini menampilkan informasi mengenai presentasi dan tampilan dokumen.

Zoom Slider

Zoom digunakan untuk memperbesar atau memperkecil tampilan slide pada layar.

💡 Tips:

Zoom hanya mengubah ukuran tampilan di layar. Zoom tidak mengubah ukuran sebenarnya dari slide.

10. Mengatur Ukuran Slide

Ukuran slide menentukan bentuk dan perbandingan bidang presentasi yang digunakan.

Untuk mengatur ukuran slide:

Design → Slide Size → Custom Slide Size

Ukuran yang Umum Digunakan

Ukuran Perbandingan Penggunaan
Standard 4 : 3 Presentasi pada perangkat atau proyektor lama.
Widescreen 16 : 9 Monitor, laptop, TV, dan proyektor modern.
Custom Sesuai kebutuhan Poster, infografis, banner, dan kebutuhan khusus.
📌 Rekomendasi:

Untuk presentasi modern, ukuran Widescreen 16:9 merupakan pilihan yang umum digunakan.

11. Custom Slide Size

Custom Slide Size digunakan apabila pengguna membutuhkan ukuran slide tertentu.

Pada jendela Custom Slide Size, pengguna dapat mengatur:

  • Width — lebar slide.
  • Height — tinggi slide.
  • Orientation — orientasi slide.
Contoh ukuran:
  • Widescreen: 13,333 × 7,5 inci
  • Standard: 10 × 7,5 inci

12. Mengatur Orientasi Slide

Orientasi menentukan arah tampilan slide.

Orientasi Keterangan
Landscape Slide berbentuk horizontal. Umumnya digunakan untuk presentasi.
Portrait Slide berbentuk vertikal. Cocok untuk poster atau materi tertentu.
