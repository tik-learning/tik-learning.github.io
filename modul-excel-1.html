💻 1. Berkenalan dengan Microsoft Excel

Microsoft Excel adalah aplikasi pengolah angka atau spreadsheet yang dikembangkan oleh Microsoft.

Excel digunakan untuk mengolah data dalam bentuk tabel, melakukan perhitungan, membuat laporan, menganalisis data, dan menyajikan data dalam bentuk grafik.

Contoh penggunaan Excel

📊

Pengolahan Data

Mengelola data peserta, pegawai, barang, dan lainnya.

💰

Keuangan

Membuat anggaran dan laporan keuangan.

📈

Analisis

Menganalisis dan membandingkan data.

📋

Laporan

Membuat laporan secara terstruktur.

Istilah dasar Excel

Istilah Pengertian
Workbook File atau dokumen Excel.
Worksheet Lembar kerja dalam workbook.
Row Baris yang ditandai dengan angka.
Column Kolom yang ditandai dengan huruf.
Cell Pertemuan antara baris dan kolom.
Range Kumpulan beberapa cell.
Formula Rumus yang digunakan untuk melakukan perhitungan.
Function Fungsi bawaan Excel.

🚀 2. Cara Membuka Microsoft Excel

Cara 1 – Melalui Start Menu

  1. Klik tombol Start.
  2. Cari Microsoft Excel.
  3. Klik Microsoft Excel.
  4. Tunggu sampai Excel terbuka.

Cara 2 – Menggunakan Search Windows

  1. Tekan tombol Windows.
  2. Ketik Excel.
  3. Pilih Microsoft Excel.
  4. Tekan Enter.

Cara 3 – Shortcut Desktop

  1. Cari ikon Microsoft Excel di Desktop.
  2. Klik dua kali ikon tersebut.

Cara 4 – Membuka File Excel

  1. Buka folder tempat file disimpan.
  2. Cari file Excel.
  3. Klik dua kali file tersebut.
Tips: Cara tercepat untuk mencari Excel di Windows adalah menekan tombol Windows kemudian mengetik Excel.

🖥️ 3. Mengenal Antarmuka Microsoft Excel

1. Title Bar

Menampilkan nama file yang sedang dibuka.

2. Quick Access Toolbar

Berisi perintah yang sering digunakan, seperti:

  • Save
  • Undo
  • Redo

3. Ribbon

Ribbon berisi berbagai menu dan perintah Excel. Contoh tab:

Name Box menunjukkan alamat cell yang sedang aktif.

📑 4. Worksheet dan Workbook

Worksheet

Worksheet adalah lembar kerja tempat kita memasukkan dan mengolah data.

Sheet1 | Sheet2 | Sheet3

Contoh:

  • Sheet1 = Data Peserta
  • Sheet2 = Nilai
  • Sheet3 = Rekapitulasi

Workbook

Workbook adalah keseluruhan file Excel. Satu workbook dapat memiliki beberapa worksheet.

Hubungan:

Workbook → Worksheet → Cell

💾 5. Format File Microsoft Excel

Format Nama Keterangan
.xlsx Excel Workbook Format Excel modern dan paling umum.
.xls Excel 97–2003 Format Excel versi lama.
.xlsm Excel Macro-Enabled Mendukung Macro/VBA.
.csv Comma-Separated Values Digunakan untuk pertukaran data.
Perhatian: Jika workbook memiliki Macro/VBA, jangan menyimpannya sebagai .xlsx karena Macro dapat hilang. Gunakan format .xlsm.

⚙️ 6. Penting Sebelum Memulai Excel

1. Tentukan tujuan pengolahan data

Tentukan terlebih dahulu data apa yang akan dibuat.

  • Data peserta
  • Data pegawai
  • Data inventaris
  • Data penjualan
  • Data keuangan

2. Buat struktur tabel

No Nama NIK Program Nilai
1 Andi 327... Las 85
2 Budi 327... TIK 90

3. Gunakan satu jenis data untuk satu kolom

Contohnya kolom Nilai hanya berisi angka. Jangan mencampurkan angka dengan keterangan.

❌ Salah: 85 Lulus

✅ Lebih baik:
Nilai Keterangan
85 Lulus

4. Hindari Merge Cell pada database

Merge Cell sebaiknya tidak digunakan pada tabel data utama karena dapat menyulitkan Sort, Filter, dan pengolahan data.

5. Simpan pekerjaan secara berkala

Ctrl + S

Biasakan menyimpan file secara berkala untuk mencegah kehilangan pekerjaan.

🌏 7. Region Setting

Region Setting adalah pengaturan wilayah pada Windows yang memengaruhi format tanggal, angka, waktu, dan mata uang.

Mengapa penting untuk Excel?

Region Setting dapat memengaruhi bagaimana Excel membaca angka, tanggal, dan formula.

Format Indonesia

Pengaturan Format Indonesia
Pemisah desimal ,
Pemisah ribuan .
Format tanggal dd/mm/yyyy

Contoh

1.500,50

Dalam format Indonesia, angka tersebut dapat berarti seribu lima ratus koma lima puluh.

🛠️ 8. Cara Mengecek Region Setting Windows

  1. Buka Control Panel.
  2. Pilih Clock and Region.
  3. Pilih Region.
  4. Perhatikan bagian Format.
  5. Pilih Indonesian (Indonesia).
  6. Klik Apply.
  7. Klik OK.
Catatan: Pengaturan tampilan pada Windows dapat sedikit berbeda tergantung versi Windows yang digunakan.

🔢 9. Pengaturan Angka dan Formula

Pada format Indonesia umumnya digunakan:

Decimal Symbol

,

Contoh: 10,5

Digit Grouping

.

Contoh: 10.000

Pemisah formula

Tergantung pengaturan regional, Excel dapat menggunakan tanda ; sebagai pemisah argument.

=SUM(A1;B1)
Jika menemukan rumus dari internet menggunakan tanda , sedangkan Excel Anda menggunakan ;, jangan langsung menganggap rumusnya salah. Perhatikan pengaturan regional Excel.
