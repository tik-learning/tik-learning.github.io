MODUL 9

⚙️ Macro & Otomatisasi Tingkat Lanjut

Microsoft Word 2016

Pada modul ini peserta akan mempelajari bagaimana menggunakan Macro dan VBA untuk mengotomatisasi pekerjaan yang dilakukan berulang kali pada Microsoft Word.

1. Pengenalan Macro pada Microsoft Word 2016

Macro adalah serangkaian perintah yang direkam atau ditulis menggunakan VBA (Visual Basic for Applications) untuk menjalankan pekerjaan secara otomatis.

Dengan Macro, pekerjaan yang sebelumnya harus dilakukan secara berulang dapat dijalankan hanya dengan satu perintah atau satu tombol.

Contoh penggunaan:
  • Mengatur format dokumen secara otomatis.
  • Membuat format laporan yang seragam.
  • Menjalankan beberapa perintah sekaligus.
  • Membantu pekerjaan administrasi yang berulang.

2. Mengenal Developer Tab

Tab Developer merupakan bagian penting untuk bekerja dengan Macro, VBA, dan kontrol formulir di Microsoft Word.

Cara menampilkan Developer

Langkah 1: Klik File → Options
Langkah 2: Pilih Customize Ribbon
Langkah 3: Beri tanda centang pada Developer
Langkah 4: Klik OK

Setelah berhasil, tab Developer akan muncul pada Ribbon Microsoft Word.

3. Membuat Macro dengan Record Macro

Record Macro memungkinkan pengguna merekam tindakan yang dilakukan di Word kemudian menjalankannya kembali secara otomatis.

Langkah 1: Buka tab View → Macros → Record Macro
Langkah 2: Masukkan nama Macro.
Langkah 3: Tentukan apakah Macro akan dijalankan melalui tombol atau keyboard shortcut.
Langkah 4: Lakukan pekerjaan yang ingin direkam.
Langkah 5: Pilih View → Macros → Stop Recording.
Tips: Buat nama Macro yang mudah dikenali, misalnya: FormatLaporan atau FormatSurat.

4. Menjalankan Macro

Macro yang telah dibuat dapat dijalankan melalui beberapa cara.

  • Melalui menu Macro.
  • Menggunakan keyboard shortcut.
  • Menggunakan tombol yang telah dibuat.
Contoh: Jika Macro bernama FormatLaporan memiliki shortcut tertentu, pengguna dapat menjalankan seluruh rangkaian format hanya dengan menekan shortcut tersebut.

5. Mengenal Visual Basic Editor

Macro pada Microsoft Word dapat dilihat dan diedit melalui Visual Basic Editor atau VBE.

Untuk membukanya dapat menggunakan:

Developer → Visual Basic

Di dalam Visual Basic Editor, Macro ditulis menggunakan bahasa pemrograman VBA.

6. Pengenalan VBA Dasar

VBA merupakan bahasa pemrograman yang digunakan untuk mengendalikan dan mengotomatisasi aplikasi Microsoft Office.

Struktur sederhana sebuah Macro VBA adalah:

Sub ContohMacro() MsgBox "Selamat datang di TIK Learning!" End Sub

Ketika Macro tersebut dijalankan, Word akan menampilkan kotak pesan.

Sub digunakan untuk memulai prosedur Macro, sedangkan End Sub menandai akhir prosedur.

7. Membuat Pesan Otomatis dengan MsgBox

Salah satu perintah VBA yang sederhana adalah MsgBox.

Sub PesanTIK() MsgBox "Dokumen berhasil diproses." End Sub

Macro tersebut akan menampilkan pesan setelah dijalankan.

8. Macro untuk Pemformatan Otomatis

Macro dapat digunakan untuk menerapkan format tertentu secara otomatis.

Contohnya adalah membuat seluruh teks terpilih menjadi tebal dan rata tengah.

Sub FormatJudul() Selection.Font.Bold = True Selection.ParagraphFormat.Alignment = wdAlignParagraphCenter End Sub

Dengan Macro tersebut, pekerjaan yang biasanya dilakukan melalui beberapa menu dapat dijalankan secara otomatis.

9. Macro untuk Pekerjaan Berulang

Salah satu manfaat terbesar Macro adalah mengurangi pekerjaan manual yang dilakukan berulang kali.

Pekerjaan Tanpa Macro Dengan Macro
Format judul Dilakukan manual Satu perintah
Format laporan Berulang Otomatis
Menampilkan pesan Tidak otomatis MsgBox
Pekerjaan administratif Banyak langkah Dapat disederhanakan

10. Membuat Tombol untuk Menjalankan Macro

Macro dapat dihubungkan dengan tombol sehingga pengguna tidak perlu membuka menu Macro setiap kali ingin menjalankannya.

Langkah 1: Buka tab Developer.
Langkah 2: Gunakan kontrol atau perintah yang sesuai untuk membuat tombol.
Langkah 3: Hubungkan tombol dengan Macro.
Langkah 4: Uji tombol tersebut.

11. Macro dan Template

Macro dapat digunakan bersama template untuk membuat dokumen dengan format yang lebih terstandar.

Dalam pekerjaan administrasi, pendekatan ini dapat membantu membuat dokumen yang memiliki struktur dan format yang konsisten.

Format penting:
  • .docm — dokumen Word yang dapat menyimpan Macro.
  • .dotm — template Word yang dapat menyimpan Macro.

12. Keamanan Macro

Macro memberikan kemampuan otomatisasi yang kuat, tetapi Macro juga dapat digunakan untuk menjalankan kode yang tidak aman.

⚠️ Penting! Jangan mengaktifkan Macro dari dokumen yang berasal dari sumber yang tidak dipercaya.

Hal yang perlu diperhatikan

  • Periksa sumber dokumen sebelum mengaktifkan Macro.
  • Jangan sembarangan memilih Enable Content.
  • Gunakan dokumen Macro-enabled hanya ketika diperlukan.
  • Pahami kode Macro sebelum menggunakannya.

13. Studi Kasus Otomatisasi Administrasi

Bayangkan seorang staf harus membuat puluhan dokumen laporan dengan format yang sama.

Tanpa otomatisasi, setiap dokumen harus diformat satu per satu.

Dengan Macro, beberapa pekerjaan dapat dibuat menjadi satu rangkaian perintah.

Contoh alur:
  1. Membuka dokumen.
  2. Menjalankan Macro.
  3. Macro menerapkan format standar.
  4. Macro menampilkan pesan bahwa proses selesai.

14. Latihan Praktik Modul 9

Buatlah sebuah Macro sederhana yang dapat digunakan untuk membantu pekerjaan administrasi.

Tugas 1: Aktifkan tab Developer pada Microsoft Word 2016.
Tugas 2: Buat Macro dengan nama FormatJudul.
Tugas 3: Atur Macro agar judul menjadi tebal dan berada di tengah halaman.
Tugas 4: Buat Macro kedua yang menampilkan pesan: "Dokumen berhasil diproses."
Tugas 5: Jalankan kedua Macro tersebut dan pastikan berfungsi.

🏆 Proyek Praktik Modul 9

Buat sebuah Template Dokumen Administrasi Otomatis menggunakan Microsoft Word 2016.

Template minimal memiliki:

  • Format judul yang konsisten.
  • Macro untuk menjalankan pemformatan.
  • Tombol atau shortcut untuk menjalankan Macro.
  • Pesan otomatis setelah proses selesai.
  • File disimpan dalam format Macro-enabled.

Tujuan: peserta mampu membuat solusi otomatisasi sederhana yang dapat digunakan dalam pekerjaan administrasi.

  • Developer merupakan tab penting untuk bekerja dengan Macro dan VBA.

  • VBA memungkinkan pengguna membuat otomatisasi yang lebih fleksibel.
  • Macro dapat dihubungkan dengan tombol atau shortcut.
  • Dokumen Macro-enabled menggunakan format seperti .docm dan .dotm.
