MODUL 4 — TINGKAT MENENGAH

📄 Menambahkan dan Mengelola Elemen Dokumen

Microsoft Word 2016

Pada modul ini peserta mulai mempelajari cara membuat dokumen yang lebih lengkap, rapi, dan profesional dengan memanfaatkan berbagai elemen dalam Microsoft Word.

🎯 Tujuan Pembelajaran

Setelah menyelesaikan Modul 4, peserta diharapkan mampu:

  1. Membuat dan mengatur tabel dalam dokumen.
  2. Menyisipkan dan mengatur gambar.
  3. Menggunakan Text Wrapping.
  4. Membuat dan mengatur Shapes.
  5. Membuat Text Box dan WordArt.
  6. Membuat Header dan Footer.
  7. Menambahkan nomor halaman.
  8. Menyisipkan simbol dan karakter khusus.
  9. Mengatur posisi dan susunan objek.
  10. Menggabungkan berbagai elemen untuk menghasilkan dokumen profesional.

1. Membuat Tabel

Tabel digunakan untuk menyajikan informasi dalam bentuk baris dan kolom sehingga data menjadi lebih mudah dibaca dan dipahami.

Tabel banyak digunakan dalam dokumen administrasi, seperti:

  • Daftar peserta pelatihan
  • Jadwal pelatihan
  • Daftar nilai
  • Daftar inventaris
  • Daftar harga
  • Rekap kehadiran

Cara Membuat Tabel

  1. Buka Microsoft Word.
  2. Pilih tab Insert.
  3. Klik Table.
  4. Pilih jumlah baris dan kolom.

Contoh Tabel

No Nama Peserta Kejuruan Nilai
1 Andi TIK 85
2 Budi TIK 90
3 Siti TIK 88
💡 Tips: Gunakan tabel untuk data yang memiliki hubungan antarbaris dan kolom agar informasi lebih mudah dibaca.

2. Mengatur Tampilan Tabel

Setelah membuat tabel, tampilannya dapat disesuaikan agar lebih rapi dan profesional.

Klik tabel kemudian gunakan:

Table Tools → Design

Beberapa fitur yang dapat digunakan:

  • Table Styles
  • Shading
  • Borders
  • Border Color
  • Border Style
  • Border Width

3. Menyisipkan Gambar

Gambar dapat digunakan untuk memperjelas informasi dalam dokumen.

Contohnya:

  • Logo instansi
  • Foto kegiatan
  • Foto produk
  • Ilustrasi
  • Diagram
  • Dokumentasi kegiatan

Cara Menyisipkan Gambar

  1. Pilih Insert.
  2. Klik Pictures.
  3. Pilih gambar dari komputer.
  4. Klik Insert.

4. Mengubah Ukuran Gambar

Ukuran gambar dapat disesuaikan agar tidak terlalu besar atau terlalu kecil.

Klik gambar kemudian pilih:

Picture Tools → Format → Size

Peserta dapat mengatur:

  • Height
  • Width
💡 Tips: Gunakan bagian sudut gambar ketika memperbesar atau memperkecil gambar agar proporsinya tetap terjaga.

5. Mengatur Posisi Gambar dengan Text Wrapping

Text Wrapping digunakan untuk mengatur hubungan antara gambar dengan teks di sekitarnya.

Pilih gambar kemudian:

Picture Tools → Format → Wrap Text

Jenis Text Wrapping

  • In Line with Text — gambar dianggap seperti karakter teks.
  • Square — teks mengelilingi gambar.
  • Tight — teks mengikuti bentuk objek.
  • Behind Text — gambar berada di belakang teks.
  • In Front of Text — gambar berada di depan teks.
  • Top and Bottom — teks berada di atas dan bawah gambar.

6. Membuat Shapes

Shapes digunakan untuk membuat berbagai bentuk grafis sederhana.

Contohnya:

  • Kotak
  • Lingkaran
  • Panah
  • Garis
  • Flowchart
  • Callout

Cara Membuat Shapes

  1. Pilih Insert.
  2. Klik Shapes.
  3. Pilih bentuk yang diinginkan.
  4. Klik dan tarik pada halaman.

7. Menambahkan Teks pada Shapes

Shapes dapat digunakan sebagai tempat menampilkan teks.

Caranya:

  1. Klik kanan pada Shape.
  2. Pilih Add Text.
  3. Ketik teks.
Contoh:

PENDAFTARAN PELATIHAN

atau

INFORMASI PENTING

8. Membuat Text Box

Text Box merupakan kotak khusus yang digunakan untuk menempatkan teks pada posisi tertentu dalam dokumen.

Cara Membuat Text Box

  1. Pilih Insert.
  2. Klik Text Box.
  3. Pilih desain.
  4. Ketik teks.

Text Box dapat digunakan untuk:

  • Catatan penting
  • Informasi tambahan
  • Kutipan
  • Keterangan gambar
  • Informasi kontak

9. Menggunakan WordArt

WordArt digunakan untuk membuat teks dengan tampilan dekoratif.

Cara menggunakan WordArt

  1. Pilih Insert.
  2. Klik WordArt.
  3. Pilih gaya.
  4. Ketik teks.
💡 Gunakan WordArt secara terbatas pada dokumen resmi agar tampilan tetap profesional.

10. Membuat Header

Header adalah area pada bagian atas halaman yang dapat digunakan untuk menampilkan informasi yang berulang pada setiap halaman.

Contohnya:

UPTD BLK KABUPATEN SUBANG
PROGRAM PELATIHAN VOKASI NASIONAL

Cara Membuat Header

  1. Pilih Insert.
  2. Klik Header.
  3. Pilih desain.
  4. Masukkan informasi.

11. Membuat Footer

Footer berada di bagian bawah halaman.

Footer dapat digunakan untuk menampilkan:

  • Nama instansi
  • Nama dokumen
  • Tahun
  • Nomor dokumen
  • Nomor halaman

Cara Membuat Footer

  1. Pilih Insert.
  2. Klik Footer.
  3. Pilih desain.
  4. Masukkan informasi.

12. Menambahkan Nomor Halaman

Nomor halaman sangat penting terutama pada dokumen yang terdiri dari banyak halaman.

Cara Membuat Nomor Halaman

  1. Pilih Insert.
  2. Klik Page Number.
  3. Pilih lokasi nomor halaman.
  4. Pilih format yang diinginkan.

Nomor halaman dapat ditempatkan pada:

  • Top of Page
  • Bottom of Page
  • Page Margins
  • Current Position

13. Menyisipkan Simbol

Microsoft Word menyediakan berbagai simbol yang tidak tersedia secara langsung pada keyboard.

Contoh simbol:

©    ®    ™    ±    ≤    ≥    °

Cara Menyisipkan Simbol

  1. Pilih Insert.
  2. Klik Symbol.
  3. Pilih simbol.
  4. Klik Insert.

14. Mengatur Posisi dan Susunan Objek

Ketika sebuah dokumen memiliki banyak objek, posisi dan susunan objek harus diatur agar dokumen tetap rapi.

Gunakan menu:

Format → Arrange

Beberapa fitur penting:

  • Bring Forward
  • Send Backward
  • Bring to Front
  • Send to Back
  • Align
  • Group
  • Rotate

Group

Fitur Group digunakan untuk menggabungkan beberapa objek menjadi satu kelompok.

Misalnya sebuah desain memiliki:

  • Logo
  • Text Box
  • Shape

Ketiga objek tersebut dapat di-Group sehingga dapat dipindahkan secara bersamaan.

15. Membuat Dokumen Profesional

Setelah memahami berbagai elemen di atas, peserta mulai dapat menggabungkan beberapa fitur untuk menghasilkan dokumen yang lebih profesional.

Contohnya adalah membuat Lembar Informasi Kegiatan Pelatihan yang terdiri dari:

  • Logo instansi
  • Judul
  • Gambar
  • Tabel jadwal
  • Text Box informasi
  • Header
  • Footer
  • Nomor halaman
⚠️ Penting: Tujuan utama Modul 4 bukan hanya mengetahui fungsi setiap fitur, tetapi mampu menggabungkan fitur tersebut untuk membuat dokumen nyata yang rapi dan profesional.

Praktik: Membuat Jadwal Pelatihan Profesional

Buat sebuah dokumen Microsoft Word dengan ketentuan berikut.

A. Header

Tuliskan:

UPTD BLK KABUPATEN SUBANG

PROGRAM PELATIHAN VOKASI NASIONAL

B. Judul

Buat judul:

JADWAL PELATIHAN KEJURUAN TIK

Format:

  • Bold
  • Ukuran 18 pt
  • Rata tengah

C. Tabel

Buat tabel dengan 5 kolom:

No Hari/Tanggal Materi Waktu Instruktur
1 Senin Microsoft Word 08.00–16.00 Instruktur TIK
2 Selasa Microsoft Word 08.00–16.00 Instruktur TIK
3 Rabu Microsoft Excel 08.00–16.00 Instruktur TIK
4 Kamis Microsoft Excel 08.00–16.00 Instruktur TIK
5 Jumat Praktik 08.00–16.00 Instruktur TIK

D. Gambar

Tambahkan logo atau gambar kegiatan pelatihan.

Atur:

Wrap Text → Square

E. Text Box

Buat Text Box dengan tulisan:

INFORMASI PENTING

Peserta wajib mengikuti seluruh kegiatan pelatihan sesuai jadwal yang telah ditentukan.

F. Footer

Tambahkan:

TIK Learning – UPTD BLK Kabupaten Subang

Kemudian tambahkan nomor halaman.
