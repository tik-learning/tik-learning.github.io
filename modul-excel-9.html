2. IF Bertingkat

IF bertingkat adalah penggunaan fungsi IF lebih dari satu dalam sebuah formula untuk menguji beberapa kondisi.

IF bertingkat biasanya digunakan ketika terdapat lebih dari dua kategori hasil.

Contoh Kasus

Misalnya nilai peserta dikategorikan sebagai berikut:

Nilai Keterangan
≥ 90 Sangat Baik
≥ 80 Baik
≥ 70 Cukup
< 70 Kurang

Formula

=IF(B2>=90,"Sangat Baik",IF(B2>=80,"Baik",IF(B2>=70,"Cukup","Kurang")))

Excel akan memeriksa kondisi dari kiri ke kanan. Jika kondisi pertama benar, Excel langsung memberikan hasilnya. Jika salah, Excel memeriksa IF berikutnya.

3. Cara Kerja IF Bertingkat

1 Periksa kondisi pertama

Apakah nilai ≥ 90?

2 Jika salah

Periksa kondisi berikutnya: apakah nilai ≥ 80?

3 Jika masih salah

Periksa apakah nilai ≥ 70.

4 Jika semua salah

Berikan hasil "Kurang".

💡 Tips: Dalam membuat IF bertingkat, susun kondisi dari nilai tertinggi ke nilai terendah agar hasil lebih mudah dikontrol.

4. Contoh IF Bertingkat untuk Status Kelulusan

Misalnya nilai peserta berada pada sel C2. Kriteria:

Nilai Status
≥ 85 Lulus Sangat Baik
≥ 75 Lulus
≥ 60 Remedial
< 60 Tidak Lulus
=IF(C2>=85,"Lulus Sangat Baik",IF(C2>=75,"Lulus",IF(C2>=60,"Remedial","Tidak Lulus")))

5. VLOOKUP

VLOOKUP digunakan untuk mencari sebuah nilai pada kolom pertama sebuah tabel dan mengambil data dari kolom lain pada baris yang sama.

Huruf V pada VLOOKUP berarti Vertical.

Sintaks

=VLOOKUP(lookup_value,table_array,col_index_num,[range_lookup])

Parameter VLOOKUP

Parameter Keterangan
lookup_value Nilai yang ingin dicari.
table_array Area tabel tempat pencarian.
col_index_num Nomor kolom yang akan dikembalikan.
range_lookup TRUE atau FALSE untuk menentukan jenis pencarian.

6. Contoh VLOOKUP

Misalnya terdapat tabel data program pelatihan:

Kode Program Durasi
TK01 Teknik Las 30 Hari
TK02 Teknisi Instalasi Tenaga 35 Hari
TK03 Garmen Apparel 25 Hari

Jika kode program berada di E2 dan tabel berada di A2:C4:

=VLOOKUP(E2,A2:C4,2,FALSE)

Formula tersebut mengambil nama program dari kolom kedua.

Mengambil Durasi

=VLOOKUP(E2,A2:C4,3,FALSE)

Karena durasi berada pada kolom ketiga.

7. TRUE dan FALSE pada VLOOKUP

Argumen Keterangan
FALSE Mencari kecocokan yang tepat (exact match).
TRUE Mencari kecocokan mendekati (approximate match).

Exact Match

=VLOOKUP(E2,A2:C10,2,FALSE)

FALSE biasanya digunakan ketika mencari kode, ID, nomor peserta, NIK, atau data lain yang harus cocok secara tepat.

⚠️ Perhatian: Untuk pencarian kode atau ID yang harus sama persis, biasakan menggunakan FALSE.

8. VLOOKUP dengan Nilai Bertingkat

VLOOKUP juga dapat digunakan untuk menentukan kategori berdasarkan rentang nilai dengan menggunakan TRUE.

Nilai Minimum Predikat
0 Kurang
60 Cukup
75 Baik
85 Sangat Baik

Jika nilai berada di E2 dan tabel berada di A2:B5:

=VLOOKUP(E2,A2:B5,2,TRUE)
⚠️ Penting: Untuk approximate match menggunakan TRUE, kolom pertama tabel harus disusun secara menaik.

9. HLOOKUP

HLOOKUP digunakan untuk mencari data secara horizontal.

Huruf H berarti Horizontal.

Sintaks

=HLOOKUP(lookup_value,table_array,row_index_num,[range_lookup])

Perbedaan VLOOKUP dan HLOOKUP

VLOOKUP HLOOKUP
Pencarian vertikal Pencarian horizontal
Menggunakan nomor kolom Menggunakan nomor baris
Data kunci berada pada kolom pertama Data kunci berada pada baris pertama

10. Contoh HLOOKUP

Misalnya tabel dibuat secara horizontal:

Kode TK01 TK02 TK03
Program Teknik Las Teknisi Instalasi Tenaga Garmen Apparel
Durasi 30 Hari 35 Hari 25 Hari

Jika kode yang dicari berada di E2:

=HLOOKUP(E2,A2:D4,2,FALSE)

Formula tersebut mengambil nama program dari baris kedua.

Mengambil Durasi

=HLOOKUP(E2,A2:D4,3,FALSE)

11. Penggunaan Kombinasi Fungsi

Kombinasi fungsi berarti menggunakan dua atau lebih fungsi Excel dalam satu formula untuk menghasilkan informasi yang lebih spesifik.

Contoh fungsi yang sering dikombinasikan:

  • IF + VLOOKUP
  • IF + HLOOKUP
  • IF + AND
  • IF + OR
  • IF + COUNTIF
  • IF + SUMIF
  • IF + LEFT
  • IF + RIGHT
  • IF + MID
  • IF + ISERROR

12. Kombinasi IF + VLOOKUP

Misalnya kita ingin mencari nama program berdasarkan kode. Jika kode tidak ditemukan, kita ingin menampilkan "Kode Tidak Ditemukan".

=IF(ISERROR(VLOOKUP(E2,A2:C10,2,FALSE)),"Kode Tidak Ditemukan",VLOOKUP(E2,A2:C10,2,FALSE))

Formula tersebut menggunakan:

Fungsi Peran
VLOOKUP Mencari data program.
ISERROR Mendeteksi apakah formula menghasilkan error.
IF Menentukan hasil yang ditampilkan.
💡 Catatan Excel 2016: IFERROR juga tersedia pada Excel 2016 dan sering menjadi cara yang lebih sederhana untuk menangani error.

Menggunakan IFERROR

=IFERROR(VLOOKUP(E2,A2:C10,2,FALSE),"Kode Tidak Ditemukan")

13. Kombinasi IF + AND

Kombinasi IF dan AND digunakan ketika beberapa kondisi harus terpenuhi sekaligus.

Contoh:

  • Nilai minimal 75
  • Kehadiran minimal 80%

Jika nilai berada di B2 dan kehadiran di C2:

=IF(AND(B2>=75,C2>=80%),"Lulus","Tidak Lulus")

Peserta dinyatakan lulus hanya jika kedua kondisi terpenuhi.

14. Kombinasi IF + OR

OR digunakan ketika cukup salah satu dari beberapa kondisi yang terpenuhi.

Contoh:

Peserta mendapatkan status khusus jika nilai ≥ 90 atau kehadiran ≥ 95%.

=IF(OR(B2>=90,C2>=95%),"Peserta Terbaik","Peserta Reguler")

15. Kombinasi IF + LEFT

Kombinasi IF dengan fungsi Text dapat digunakan untuk mengidentifikasi kategori berdasarkan kode.

Misalnya:

  • TK = Teknik
  • BM = Bisnis Manajemen
  • GA = Garmen Apparel

Jika kode peserta berada di A2:

=IF(LEFT(A2,2)="TK","Teknik",IF(LEFT(A2,2)="BM","Bisnis Manajemen",IF(LEFT(A2,2)="GA","Garmen Apparel","Lainnya")))

Formula tersebut mengambil dua karakter pertama menggunakan LEFT kemudian menentukan kategori menggunakan IF bertingkat.

16. Kombinasi LEFT + VLOOKUP

Misalnya kode peserta:

TK20260025

Dua karakter pertama menunjukkan kode bidang. Tabel referensi:

Kode Bidang
TK Teknik
BM Bisnis Manajemen
GA Garmen Apparel

Formula:

=VLOOKUP(LEFT(A2,2),E2:F4,2,FALSE)

Cara kerja formula:

  1. LEFT mengambil dua karakter pertama.
  2. Hasilnya digunakan sebagai lookup_value.
  3. VLOOKUP mencari kode tersebut pada tabel referensi.
  4. Kolom kedua dikembalikan sebagai nama bidang.

17. Contoh Kombinasi Fungsi dalam Pengolahan Data

Misalnya kita memiliki data:

Nama Kode Peserta Nilai Kehadiran
Ade Suhendar TK20260025 88 90%
Budi Santoso BM20260026 72 85%
Citra Lestari GA20260027 65 70%

Menentukan Status

=IF(AND(C2>=75,D2>=80%),"Lulus","Tidak Lulus")

Mengambil Kode Bidang

=LEFT(B2,2)

Mengambil Nama Bidang dari Tabel Referensi

=VLOOKUP(LEFT(B2,2),H2:I4,2,FALSE)

Dengan kombinasi fungsi tersebut, kita dapat membuat lembar kerja yang lebih otomatis.

18. Kesalahan yang Sering Terjadi

Kesalahan Penyebab Solusi
#N/A Data tidak ditemukan. Periksa lookup_value dan tabel referensi.
#REF! Referensi cell tidak valid. Periksa area tabel.
#VALUE! Jenis data tidak sesuai. Periksa isi dan argumen formula.
Hasil salah Nomor kolom/baris salah. Periksa col_index_num atau row_index_num.
VLOOKUP tidak menemukan kode FALSE digunakan dan data tidak sama persis. Periksa penulisan kode.

💡 19. Tips Membuat Formula Kombinasi

1. Tentukan hasil yang diinginkan

Tentukan informasi apa yang ingin dihasilkan terlebih dahulu.

2. Pecah masalah menjadi beberapa fungsi

Misalnya gunakan LEFT untuk mengambil kode, kemudian VLOOKUP untuk mencari nama bidang.

3. Uji setiap fungsi secara terpisah

Pastikan setiap bagian formula menghasilkan nilai yang benar sebelum digabungkan.

4. Gunakan referensi cell dengan benar

Gunakan tanda $ jika area tabel perlu dikunci ketika formula disalin.

=VLOOKUP(LEFT(A2,2),$H$2:$I$4,2,FALSE)

📝 20. Latihan Praktik

Buat tabel peserta dengan kolom:

Nama Kode Nilai Kehadiran Bidang Status
Ade TK2026001 88 90% ? ?
Budi BM2026002 72 85% ? ?
Citra GA2026003 65 70% ? ?

Kemudian buat tabel referensi:

Kode Bidang
TK Teknik
BM Bisnis Manajemen
GA Garmen Apparel

Tugas

  1. Gunakan LEFT untuk mengambil kode bidang.
  2. Gunakan VLOOKUP untuk mencari nama bidang.
  3. Gunakan IF + AND untuk menentukan status kelulusan.
  4. Gunakan IFERROR + VLOOKUP agar kode yang tidak ditemukan tidak menampilkan error.
  5. Gunakan referensi absolut untuk mengunci tabel referensi.
🎯 Tantangan: Buat satu formula yang dapat menampilkan:

"TK - Teknik - Lulus"

Gunakan kombinasi LEFT, VLOOKUP, IF, AND dan operator penggabungan teks (&).

📌 21. Ringkasan Modul

Fungsi Kegunaan
IF Bertingkat Menguji beberapa kondisi.
VLOOKUP Mencari data secara vertikal.
HLOOKUP Mencari data secara horizontal.
IF + AND Memeriksa beberapa kondisi yang semuanya harus terpenuhi.
IF + OR Memeriksa beberapa kondisi yang salah satunya cukup terpenuhi.
IF + VLOOKUP Menggabungkan logika dengan pencarian data.
LEFT + VLOOKUP Mengambil kode kemudian mencari informasi berdasarkan kode tersebut.
IFERROR + VLOOKUP Mencegah tampilan error ketika data tidak ditemukan.

Dengan menggabungkan beberapa fungsi, pekerjaan yang sebelumnya dilakukan secara manual dapat dibuat lebih otomatis.
