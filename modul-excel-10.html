📊 MODUL 10

PivotTable — Mengolah dan Menganalisis Data dengan Cepat

🎯 Tujuan Pembelajaran

Setelah mempelajari modul ini, peserta diharapkan mampu:

  • Memahami pengertian PivotTable.
  • Mengetahui fungsi dan manfaat PivotTable.
  • Menyiapkan data yang akan digunakan sebagai sumber PivotTable.
  • Membuat PivotTable pada Microsoft Excel 2016.
  • Memahami area Rows, Columns, Values dan Filters.
  • Mengubah jenis perhitungan pada Values.
  • Melakukan filter dan sorting pada PivotTable.
  • Mengelompokkan data pada PivotTable.
  • Membuat PivotChart.
  • Melakukan Refresh PivotTable.
  • Membuat laporan sederhana menggunakan PivotTable.

1. Apa Itu PivotTable?

PivotTable adalah salah satu fitur Microsoft Excel yang digunakan untuk merangkum, menganalisis, mengeksplorasi, dan menyajikan data dalam bentuk laporan yang lebih mudah dibaca.

Dengan PivotTable, kita dapat mengolah data dalam jumlah besar tanpa harus membuat banyak formula secara manual.

Contoh:

Kita mempunyai data 1.000 peserta pelatihan yang terdiri dari nama peserta, program pelatihan, jenis kelamin, nilai, tanggal pendaftaran, dan status kelulusan.

Dengan PivotTable kita dapat dengan cepat mengetahui:

  • Jumlah peserta setiap program.
  • Jumlah peserta laki-laki dan perempuan.
  • Rata-rata nilai setiap program.
  • Jumlah peserta yang lulus.
  • Jumlah peserta berdasarkan bulan.

2. Manfaat PivotTable

Manfaat Penjelasan
Merangkum data Mengubah data mentah menjadi laporan ringkas.
Analisis data Membantu melihat pola dan perbandingan data.
Perhitungan otomatis Dapat menghitung SUM, COUNT, AVERAGE, MAX, MIN dan lainnya.
Filter data Menampilkan hanya data yang dibutuhkan.
Pengelompokan Dapat mengelompokkan data tanggal atau angka.
Visualisasi Dapat digunakan untuk membuat PivotChart.

3. Data Sumber PivotTable

Sebelum membuat PivotTable, data sumber harus disiapkan dengan baik.

Contoh Data

Tanggal Nama Program Gender Nilai Status
01/08/2026 Andi Teknik Las L 85 Lulus
02/08/2026 Budi Garmen L 78 Lulus
03/08/2026 Citra Bisnis Manajemen P 90 Lulus
04/08/2026 Dewi Teknik Las P 68 Tidak Lulus

4. Syarat Data untuk PivotTable

Data sumber sebaiknya memenuhi beberapa ketentuan.

1 Memiliki Header

Setiap kolom harus memiliki nama/header yang jelas.

2 Tidak ada baris kosong di tengah data

Baris kosong dapat menyebabkan area data tidak terbaca dengan baik.

3 Tidak ada kolom kosong di tengah tabel

Setiap kolom harus memiliki informasi yang jelas.

4 Data konsisten

Misalnya status harus konsisten menggunakan "Lulus" dan jangan sebagian menggunakan "lulus".

5 Satu baris = satu record

Setiap baris sebaiknya mewakili satu data transaksi atau peserta.

⚠️ Hindari: Menggabungkan beberapa cell pada tabel sumber, karena dapat mengganggu proses PivotTable.

5. Cara Membuat PivotTable

Langkah berikut berlaku untuk Microsoft Excel 2016.

Langkah 1

Klik salah satu cell di dalam data sumber.

Langkah 2

Klik tab Insert.

Langkah 3

Klik PivotTable.

Langkah 4

Pastikan range data sudah benar.

Langkah 5

Pilih lokasi PivotTable:

  • New Worksheet
  • Existing Worksheet
Langkah 6

Klik OK.

6. Mengenal Area PivotTable

Setelah PivotTable dibuat, Excel akan menampilkan PivotTable Fields.

Ada empat area utama:

Area Fungsi
Filters Menyaring laporan berdasarkan field tertentu.
Columns Menampilkan kategori secara horizontal.
Rows Menampilkan kategori secara vertikal.
Values Melakukan perhitungan terhadap data.
💡 Ingat 4 area PivotTable:

FILTERS → COLUMNS → ROWS → VALUES

7. Area Rows

Area Rows digunakan untuk menentukan kategori yang ditampilkan secara vertikal.

Contoh

Masukkan field Program ke area Rows.

Hasilnya dapat berupa:

Program
Bisnis Manajemen
Garmen
Teknik Las

PivotTable akan mengelompokkan data berdasarkan program.

8. Area Values

Area Values digunakan untuk melakukan perhitungan.

Misalnya kita memasukkan field Nilai. Excel dapat menghitung:

  • Sum
  • Count
  • Average
  • Max
  • Min

Contoh

Rows = Program

Values = Nilai

Jika Values menggunakan Average, hasilnya akan menampilkan rata-rata nilai setiap program.

9. Area Columns

Area Columns digunakan untuk menampilkan kategori secara horizontal.

Contoh

Rows = Program

Columns = Gender

Values = Count of Nama

Hasilnya dapat menunjukkan jumlah peserta laki-laki dan perempuan untuk setiap program.

10. Area Filters

Area Filters digunakan untuk menyaring seluruh laporan berdasarkan field tertentu.

Contoh

Jika field Status dimasukkan ke Filters, kita dapat memilih:

  • Semua status
  • Lulus
  • Tidak Lulus
💡 Contoh penggunaan:

Gunakan Filters untuk membuat laporan yang hanya menampilkan peserta dari program tertentu atau status tertentu.

11. Membuat Laporan Jumlah Peserta per Program

Misalnya ingin mengetahui jumlah peserta setiap program.

Susunan Field

Area Field
Rows Program
Values Nama

Jika field Nama berupa teks, Excel biasanya menggunakan Count of Nama.

Contoh hasil

Program Jumlah Peserta
Bisnis Manajemen 25
Garmen 30
Teknik Las 35
Total 90

12. Mengubah Jenis Perhitungan

Pada area Values, Excel memungkinkan kita mengubah jenis perhitungan.

Caranya:
  1. Klik dropdown field pada area Values.
  2. Pilih Value Field Settings.
  3. Pilih jenis perhitungan.
  4. Klik OK.
Calculation Kegunaan
Sum Menjumlahkan data.
Count Menghitung jumlah data.
Average Menghitung rata-rata.
Max Mencari nilai terbesar.
Min Mencari nilai terkecil.

13. Sorting pada PivotTable

Data PivotTable dapat diurutkan berdasarkan nama kategori atau nilai.

Contoh

Kita dapat mengurutkan program berdasarkan jumlah peserta:

  • Terbesar ke terkecil
  • Terkecil ke terbesar
💡 Manfaat:

Sorting memudahkan kita menemukan program dengan jumlah peserta terbanyak atau paling sedikit.

14. Filtering pada PivotTable

Filter dapat digunakan untuk menampilkan sebagian data saja.

Contoh

Jika ingin melihat hanya peserta yang berstatus Lulus:

  1. Masukkan Status ke Filters.
  2. Klik dropdown filter.
  3. Pilih Lulus.
  4. Klik OK.

PivotTable akan menampilkan data sesuai filter tersebut.

15. Grouping Data

PivotTable dapat digunakan untuk mengelompokkan data tertentu. Salah satu penggunaan yang paling umum adalah Grouping tanggal.

Contoh

Data pendaftaran peserta terdiri dari tanggal:

  • 01/08/2026
  • 05/08/2026
  • 12/08/2026
  • 20/08/2026

Tanggal tersebut dapat dikelompokkan berdasarkan:

  • Years
  • Quarters
  • Months
  • Days

Cara Grouping

  1. Klik salah satu tanggal pada PivotTable.
  2. Klik kanan.
  3. Pilih Group.
  4. Pilih periode yang diinginkan.
  5. Klik OK.

16. PivotChart

PivotChart adalah grafik yang terhubung dengan PivotTable.

PivotChart memudahkan kita menyajikan hasil analisis dalam bentuk visual.

Cara Membuat PivotChart

  1. Klik salah satu cell pada PivotTable.
  2. Klik tab Analyze.
  3. Klik PivotChart.
  4. Pilih jenis grafik.
  5. Klik OK.

Jenis grafik yang dapat digunakan

  • Column Chart
  • Bar Chart
  • Line Chart
  • Pie Chart
  • Area Chart
💡 Rekomendasi:

Gunakan Column Chart atau Bar Chart untuk membandingkan jumlah peserta antarprogram.

17. Refresh PivotTable

Jika data sumber berubah atau bertambah, PivotTable tidak selalu memperbarui hasil secara otomatis. Kita perlu melakukan Refresh.

Cara Refresh

  1. Klik PivotTable.
  2. Klik kanan.
  3. Pilih Refresh.

Atau gunakan:

PivotTable Tools → Analyze → Refresh

⚠️ Penting: Jika data baru berada di luar range sumber PivotTable, Refresh saja mungkin tidak cukup. Pastikan sumber data PivotTable sudah mencakup data baru.

18. Mengubah Sumber Data PivotTable

Jika range data sumber berubah, kita dapat mengubah sumber PivotTable.

  1. Klik PivotTable.
  2. Klik tab Analyze.
  3. Pilih Change Data Source.
  4. Tentukan range baru.
  5. Klik OK.

19. Menggunakan Format Table sebagai Sumber

Salah satu cara yang baik untuk mengelola data sumber adalah mengubah data menjadi Excel Table.

Caranya

  1. Blok data.
  2. Tekan Ctrl + T.
  3. Pastikan opsi My table has headers aktif.
  4. Klik OK.

Setelah menjadi Table, data lebih mudah dikelola dan dapat digunakan sebagai sumber PivotTable.

💡 Keuntungan:

Ketika data baru ditambahkan ke Table, range tabel dapat meluas secara otomatis. Namun PivotTable tetap perlu di-Refresh agar hasil analisis diperbarui.

20. Praktik Membuat Laporan Pelatihan

Gunakan data peserta pelatihan dengan kolom:

Tanggal Nama Program Gender Nilai Status
01/08/2026 Andi Teknik Las L 85 Lulus
02/08/2026 Budi Garmen L 78 Lulus
03/08/2026 Citra Bisnis Manajemen P 90 Lulus
04/08/2026 Dewi Teknik Las P 68 Tidak Lulus

Latihan 1 — Jumlah Peserta

Buat PivotTable untuk mengetahui jumlah peserta berdasarkan program.

Rows → Program
Values → Nama

Latihan 2 — Jumlah Peserta Berdasarkan Gender

Rows → Program
Columns → Gender
Values → Nama

Latihan 3 — Rata-rata Nilai

Rows → Program
Values → Nilai → Average

Latihan 4 — Peserta Lulus

Rows → Program
Values → Nama
Filters → Status

Kemudian pilih filter Lulus.

21. PivotTable untuk Laporan Profesional

PivotTable sangat berguna untuk membuat laporan manajemen.

Contoh laporan yang dapat dibuat:

  • Jumlah peserta per program.
  • Jumlah peserta berdasarkan jenis kelamin.
  • Jumlah peserta lulus dan tidak lulus.
  • Rata-rata nilai setiap program.
  • Jumlah peserta berdasarkan bulan.
  • Program dengan peserta terbanyak.
  • Program dengan rata-rata nilai tertinggi.
Konsep laporan:

Data Mentah → PivotTable → Analisis → PivotChart → Laporan

💡 22. Tips Menggunakan PivotTable

1. Rapikan data terlebih dahulu

Data yang rapi akan menghasilkan PivotTable yang lebih baik.

2. Gunakan nama header yang jelas

Hindari header kosong atau nama kolom yang membingungkan.

3. Gunakan Table

Ctrl + T dapat membantu mengelola sumber data.

4. Refresh setelah data berubah

Biasakan melakukan Refresh setelah menambah atau mengubah data.

5. Gunakan PivotChart untuk presentasi

Visualisasi membuat laporan lebih mudah dipahami.

⚠️ 23. Kesalahan yang Sering Terjadi

Masalah Penyebab Solusi
Field tidak muncul Header kosong atau data tidak terbaca. Periksa header dan range data.
Jumlah data tidak sesuai Range sumber tidak mencakup semua data. Periksa Change Data Source.
Data lama masih muncul PivotTable belum di-refresh. Klik Refresh.
Nilai menggunakan Count Field berisi teks atau Excel mendeteksinya bukan angka. Periksa tipe data sumber.
Tanggal tidak bisa dikelompokkan Data tanggal tersimpan sebagai teks. Konversi menjadi tanggal Excel yang valid.

🎓 Kesimpulan

PivotTable merupakan salah satu fitur penting Microsoft Excel untuk melakukan analisis data secara cepat dan fleksibel.

Dengan memahami Rows, Columns, Values, dan Filters, peserta dapat mengubah data mentah menjadi laporan yang lebih informatif tanpa harus membuat banyak formula.

🎯 Kompetensi akhir:

Peserta mampu membuat PivotTable sederhana, melakukan filter, sorting, grouping, mengubah perhitungan, melakukan refresh, serta membuat PivotChart untuk kebutuhan laporan.
