📋 Modul 8 — Formulir Interaktif & Protect Document

Pada modul ini peserta akan mempelajari cara membuat formulir interaktif menggunakan Microsoft Word 2016 serta melindungi dokumen agar bagian tertentu tidak dapat diubah oleh pengguna.

🎯 Kompetensi Modul:

Setelah menyelesaikan modul ini, peserta mampu membuat formulir interaktif menggunakan Text Field, Check Box, Drop-Down List, Date Picker, serta menerapkan perlindungan dokumen.

1. Mengenal Formulir Interaktif

Formulir interaktif adalah dokumen yang menyediakan bagian tertentu untuk diisi oleh pengguna secara langsung. Berbeda dengan formulir biasa, pengguna dapat mengisi kolom, memilih pilihan, atau menentukan tanggal tanpa mengubah struktur utama dokumen.

Contoh penggunaan formulir:

  • Formulir pendaftaran peserta pelatihan.
  • Formulir data peserta.
  • Formulir evaluasi.
  • Formulir administrasi kantor.
  • Formulir pemeriksaan atau pendataan.

2. Mengaktifkan Tab Developer

Fitur untuk membuat formulir interaktif terdapat pada tab Developer. Pada beberapa instalasi Microsoft Word, tab ini belum ditampilkan sehingga perlu diaktifkan terlebih dahulu.

Langkah mengaktifkan Developer:

1
Klik File.
2
Pilih Options.
3
Pilih Customize Ribbon.
4
Beri tanda centang pada Developer.
5
Klik OK.
💡 Hasil:

Tab Developer akan muncul pada Ribbon Microsoft Word.

3. Mengenal Controls pada Developer

Pada tab Developer terdapat beberapa kontrol yang dapat digunakan untuk membuat formulir interaktif.

  • Rich Text Content Control — menyediakan area untuk memasukkan teks dengan format tertentu.
  • Plain Text Content Control — digunakan untuk memasukkan teks sederhana.
  • Check Box — digunakan untuk pilihan yang dapat dicentang.
  • Drop-Down List — digunakan untuk memilih satu pilihan dari daftar.
  • Date Picker — digunakan untuk memilih tanggal.

4. Membuat Text Field

Text Field digunakan untuk menyediakan tempat bagi pengguna untuk memasukkan informasi berupa teks.

Contoh:

Langkah di Word:

Letakkan kursor pada posisi yang diinginkan, kemudian pilih: Developer → Plain Text Content Control.

5. Membuat Check Box

Check Box digunakan apabila pengguna dapat memilih lebih dari satu pilihan.

Contoh:

Keterampilan yang dikuasai:

☐ Microsoft Word

☐ Microsoft Excel

☐ Microsoft PowerPoint

☐ Internet

Pada Word, gunakan: Developer → Check Box Content Control.

6. Membuat Drop-Down List

Drop-Down List memungkinkan pengguna memilih salah satu pilihan yang telah disediakan.

Contoh:

Langkah:

Pilih: Developer → Drop-Down List Content Control

Kemudian gunakan Properties untuk menambahkan pilihan.

7. Membuat Date Picker

Date Picker digunakan untuk membuat kolom tanggal yang dapat dipilih menggunakan kalender.

Pada Word gunakan: Developer → Date Picker Content Control .

8. Mengatur Properties Form

Setiap Content Control dapat diatur melalui menu Properties.

Beberapa pengaturan yang dapat dilakukan antara lain:

  • Memberikan judul kontrol.
  • Memberikan tag.
  • Mengatur pilihan Drop-Down.
  • Mengatur tampilan kontrol.
  • Mengatur pilihan tanggal.
⚠️ Perhatian:

Atur Properties dengan baik sebelum dokumen diproteksi agar formulir mudah digunakan.

9. Membuat Formulir Profesional

Formulir yang baik harus memiliki struktur yang jelas, mudah dibaca, dan menyediakan ruang yang cukup untuk setiap informasi yang diperlukan.

Contoh struktur formulir:

FORMULIR PENDAFTARAN PESERTA PELATIHAN

10. Protect Document

Protect Document digunakan untuk membatasi perubahan pada dokumen sehingga pengguna tidak dapat mengubah bagian-bagian tertentu secara bebas.

Langkah perlindungan dokumen:

1
Buka tab Developer.
2
Pilih Restrict Editing.
3
Atur pembatasan pengeditan sesuai kebutuhan.
4
Aktifkan perlindungan dokumen.
🎯 Tujuan:

Pengguna dapat mengisi bagian formulir tanpa mengubah struktur utama dokumen.

11. Memberikan Password

Password dapat digunakan untuk mencegah orang lain menghentikan perlindungan dokumen tanpa izin.

Setelah pengaturan pembatasan selesai, pilih opsi untuk memulai perlindungan dan masukkan password yang diinginkan.

🔐 Penting:

Simpan password di tempat yang aman. Jika password lupa, proses membuka proteksi dapat menjadi sulit.

12. Menghentikan Proteksi

Jika pemilik dokumen perlu melakukan perubahan, perlindungan dapat dihentikan melalui menu Restrict Editing.

Apabila dokumen dilindungi dengan password, password harus dimasukkan untuk menghentikan proteksi.

13. Menguji Formulir

Sebelum formulir dibagikan kepada peserta, lakukan pengujian terlebih dahulu.

  • Pastikan semua kolom dapat diisi.
  • Pastikan Check Box dapat dipilih.
  • Pastikan Drop-Down memiliki pilihan yang benar.
  • Pastikan Date Picker berfungsi.
  • Pastikan struktur dokumen tidak berubah.
  • Pastikan proteksi bekerja dengan baik.
  • Pastikan password dapat digunakan.

📝 Latihan Praktik Modul 8

Buatlah sebuah dokumen Microsoft Word dengan judul:

FORMULIR PENDAFTARAN PESERTA PELATIHAN UPTD BLK KABUPATEN SUBANG

Ketentuan:

  • Buat minimal 5 Text Field.
  • Buat minimal 3 Check Box.
  • Buat minimal 2 Drop-Down List.
  • Buat minimal 1 Date Picker.
  • Atur Properties setiap kontrol.
  • Lindungi dokumen menggunakan Restrict Editing.
  • Gunakan password untuk melindungi dokumen.

🎯 Target hasil:

Dokumen harus dapat digunakan sebagai formulir digital yang dapat diisi pengguna, tetapi struktur dan bagian utama dokumen tidak dapat diubah sembarangan.

🏆 Kompetensi yang Diharapkan

Setelah menyelesaikan Modul 8, peserta mampu:

  • Membuat formulir interaktif di Microsoft Word.
  • Menggunakan Text Field, Check Box, Drop-Down List, dan Date Picker.
  • Mengatur Properties Content Control.
  • Membuat formulir yang rapi dan profesional.
  • Menggunakan Restrict Editing.
  • Melindungi dokumen menggunakan password.
