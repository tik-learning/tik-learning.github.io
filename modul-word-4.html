MODUL 4 • MICROSOFT WORD 2016

Menambahkan & Mengelola Elemen Dokumen

Mempelajari cara membuat, menyisipkan, mengatur, dan mengelola tabel, gambar, Shapes, Text Box, WordArt, Header, Footer, nomor halaman, serta berbagai objek dalam dokumen Word.

📚 Tentang Modul

Pada modul ini peserta mempelajari cara menambahkan dan mengelola berbagai elemen ke dalam dokumen Microsoft Word 2016. Peserta tidak hanya belajar memasukkan objek, tetapi juga belajar mengatur ukuran, posisi, perataan, dan hubungan antara objek dengan teks agar dokumen menjadi rapi, informatif, dan mudah dibaca.

Kompetensi utama: Mampu menambahkan, mengatur, dan mengelola berbagai elemen dokumen menggunakan Microsoft Word 2016.

1. 📊 Membuat Tabel

Tabel digunakan untuk menyajikan data dalam bentuk baris dan kolom sehingga informasi lebih mudah dibaca, dibandingkan, dan dikelola.

Contoh penggunaan tabel

  • Daftar peserta
  • Jadwal kegiatan
  • Daftar barang
  • Daftar nilai
  • Data inventaris
  • Daftar harga

Cara membuat tabel

Langkah: Insert → Table kemudian pilih jumlah kolom dan baris.
No Nama Program Nilai
1 Andi TIK 85
2 Budi TIK 90
3 Citra TIK 88

Menambahkan baris atau kolom

  • Insert Rows Above — menambah baris di atas.
  • Insert Rows Below — menambah baris di bawah.
  • Insert Columns to the Left — menambah kolom di kiri.
  • Insert Columns to the Right — menambah kolom di kanan.

Menghapus baris, kolom, atau tabel

Table Tools → Layout → Delete
  • Delete Cells
  • Delete Columns
  • Delete Rows
  • Delete Table

Merge Cells

Merge Cells digunakan untuk menggabungkan dua atau lebih sel menjadi satu.

Table Tools → Layout → Merge Cells

Split Cells

Split Cells digunakan untuk membagi satu sel menjadi beberapa sel.

Table Tools → Layout → Split Cells
Ingat: Merge Cells = menggabungkan sel. Split Cells = membagi sel.

2. 🎨 Memformat Tabel

Tabel yang sudah dibuat perlu diatur agar tampilannya mudah dibaca dan sesuai dengan kebutuhan dokumen.

Hal yang dapat diatur

  • Lebar kolom dan tinggi baris.
  • AutoFit.
  • Perataan teks.
  • Border atau garis tabel.
  • Ketebalan garis.
  • Shading atau warna latar sel.
  • Table Styles.

AutoFit

AutoFit membantu menyesuaikan ukuran tabel dengan isi atau ukuran halaman.

Table Tools → Layout → AutoFit

Perataan isi tabel

Isi tabel dapat dibuat rata kiri, tengah, atau kanan sesuai jenis datanya. Angka biasanya lebih mudah dibaca jika disusun secara konsisten.

3. 🖼️ Menyisipkan dan Mengatur Gambar

Gambar dapat digunakan sebagai ilustrasi, logo, foto kegiatan, dokumentasi, atau pendukung informasi.

Memasukkan gambar

Insert → Pictures → pilih gambar → Insert.

Mengatur ukuran gambar

  • Memperbesar gambar.
  • Memperkecil gambar.
  • Mengatur tinggi dan lebar.
  • Melakukan Crop.
  • Menjaga proporsi gambar agar tidak gepeng atau melebar.
Perhatian: Jangan mengubah ukuran gambar secara sembarangan hingga bentuk aslinya berubah. Usahakan proporsi gambar tetap terjaga.

Mengatur posisi gambar

Picture Tools → Format → Position

Selain Position, pengaturan gambar juga sangat berkaitan dengan Wrap Text.

4. ↔️ Text Wrapping

Text Wrapping menentukan bagaimana teks ditempatkan terhadap gambar atau objek.

Jenis Text Wrapping yang perlu dipahami

In Line with Text

Gambar diperlakukan seperti karakter teks dan berada pada aliran teks.

Square

Teks mengelilingi gambar dalam area berbentuk kotak.

Tight

Teks mengikuti bentuk objek secara lebih dekat.

Through

Teks dapat mengalir melalui area tertentu yang transparan pada objek.

Top and Bottom

Teks hanya berada di bagian atas dan bawah objek.

Behind Text

Objek ditempatkan di belakang teks.

In Front of Text

Objek ditempatkan di depan teks.

Cara mengatur

Pilih gambar → Picture Tools → Format → Wrap Text → pilih jenis Text Wrapping.
Latihan penting: Cobalah semua jenis Text Wrapping menggunakan satu gambar. Amati perubahan posisi teks terhadap gambar.

5. 🔷 Shapes

Shapes digunakan untuk membuat objek grafis sederhana seperti kotak, lingkaran, garis, panah, segitiga, dan callout.

Cara memasukkan Shape

Insert → Shapes → pilih bentuk → klik dan tarik pada halaman.

Yang dapat dilakukan pada Shape

  • Mengubah ukuran.
  • Memindahkan objek.
  • Mengubah warna bagian dalam.
  • Mengubah warna garis.
  • Mengubah ketebalan garis.
  • Menambahkan teks ke dalam Shape.
  • Mengatur posisi objek.
  • Mengatur urutan objek di depan atau belakang.

Shape Fill dan Shape Outline

Pilih Shape → Drawing Tools → Format → gunakan Shape Fill dan Shape Outline.

Bring Forward dan Send Backward

  • Bring Forward — membawa objek ke depan.
  • Send Backward — mengirim objek ke belakang.

6. 📝 Text Box

Text Box digunakan untuk menempatkan teks pada area tertentu secara lebih fleksibel dibandingkan teks biasa.

Contoh penggunaan

  • Informasi penting.
  • Catatan.
  • Pengumuman.
  • Kutipan.
  • Keterangan gambar.
  • Highlight informasi.

Cara membuat Text Box

Insert → Text Box → pilih model atau buat Text Box sendiri.

Pengaturan Text Box

  • Mengubah ukuran.
  • Memindahkan posisi.
  • Mengubah Shape Fill.
  • Mengubah Shape Outline.
  • Mengatur Wrap Text.

7. ✨ WordArt

WordArt digunakan untuk membuat teks dekoratif dan menarik perhatian.

Cara membuat WordArt

Insert → WordArt → pilih gaya → ketik teks.

Pengaturan WordArt

  • Mengubah ukuran teks.
  • Mengubah warna teks.
  • Mengubah outline.
  • Menggunakan Text Effects.
  • Mengatur posisi dan Wrap Text.
Tips: WordArt sebaiknya digunakan secukupnya, terutama pada dokumen resmi. Gunakan untuk judul atau bagian yang memang membutuhkan penekanan visual.

8. 🧩 Mengelola Beberapa Objek

Ketika dokumen memiliki beberapa objek, peserta perlu mengetahui cara memilih, meratakan, mengatur urutan, dan mengelompokkan objek.

Align

Align digunakan untuk membuat beberapa objek tersusun sejajar.

  • Align Left
  • Align Center
  • Align Right
  • Align Top
  • Align Middle
  • Align Bottom

Group

Group digunakan agar beberapa objek dapat diperlakukan sebagai satu kesatuan.

Pilih beberapa objek → Shape Format → Group → Group

Ungroup

Ungroup digunakan untuk memisahkan kembali objek yang sebelumnya sudah digabungkan.

Pilih objek yang sudah di-Group → Group → Ungroup
Tips praktik: Gunakan Align untuk merapikan posisi objek sebelum menggunakan Group.

9. 📄 Header dan Footer

Header

Header adalah bagian dokumen yang berada di bagian atas halaman.

Contoh:

UPTD BLK KABUPATEN SUBANG
PELATIHAN BERBASIS KOMPETENSI

Footer

Footer adalah bagian dokumen yang berada di bagian bawah halaman.

Contoh:

Modul Pelatihan TIK — Microsoft Word 2016

Cara membuat Header

Insert → Header

Cara membuat Footer

Insert → Footer

10. 🔢 Nomor Halaman

Nomor halaman digunakan untuk membantu pembaca mengetahui posisi halaman dalam dokumen.

Cara menambahkan nomor halaman

Insert → Page Number

Nomor halaman dapat ditempatkan pada:

  • Top of Page
  • Bottom of Page
  • Page Margins
  • Current Position
Catatan: Nomor halaman biasanya diletakkan pada Header atau Footer agar tampil konsisten di seluruh halaman.
